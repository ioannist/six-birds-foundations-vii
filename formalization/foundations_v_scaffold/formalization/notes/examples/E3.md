# E3 - Self-Maintaining Reclosure Law (Operator Maintenance)

**Source text:** THEOREMS.md §3, E3.  
**Target Lean module:** `SixBirdsFoundationsV.Laws.E3SelfMaintainingReclosure`.  
**Grounding:** D3 supplies carried records and source classes; D4 supplies `ESystem`, `ActiveCarriedInstrument`, `S.I_S`, `S.Lambda_S`, `S.T.suppK`, and repair-step gate/audit hooks; E1 supplies endogenous repair occurrence and gate-passing discipline; E2 supplies the finite, non-self-certifying audit-tower stop for regress. F19/F20 object-level persistence and record-coherence content are not vendored in this repo, so E3 treats the object-level fixed-point side as certified host input, following E7's F19 precedent.

## 1. Setup

Let

```text
S : ESystem ...
T := S.T
H : ChallengeHistory ChallengeClass SourceQuotient DeclaredFamily
      TargetReadout ObstructionWitness DefectRecord MoveRecord AuditRecord
```

be a D4 E-system with the D5/E1 challenge-history surface available when challenged apparatus repair is discussed. E3 is not a new definition of object persistence. It asks whether the closure-making apparatus is itself reinstated by the system.

D4 already exposes one running carried instrument:

```text
S.I_S : ActiveCarriedInstrument ...
```

with gate and audit fields:

```text
S.I_S.Detects
S.I_S.GateAllows
S.I_S.ReAudits
S.I_S.visibilityRecords
S.I_S.thresholdRecords
S.I_S.checkRuleRecords
```

E3 builds a time-indexed closure apparatus on top of that existing D4 instrument surface. It does not duplicate D4's instrument definition, and it avoids the E7 boundary-name collision by using `ClosureApparatusBoundary` / `AppBoundary`, never `BoundaryNonclosure`.

### Closure apparatus

For a time `t`, write:

```text
structure ClosureApparatus where
  time : Nat
  gateInstrument : ActiveCarriedInstrument ...
  thresholdRecords : List InstrumentRecord
  appBoundary : ClosureApparatusBoundary
  auditData : ClosureApparatusAuditData
  apparatusRecord : ClosureApparatusRecord
  usedLedgerEntries : List LedgerEntry
  usedAuditRecords : List AuditRecord
```

`ClosureApparatusBoundary` is E3's boundary component `B_t`: the boundary that says which states, thresholds, or closure conditions are inside the current closure apparatus. It is deliberately not E7's `BoundaryNonclosureCase`, which is an alarm disposition/status branch.

The apparatus is credited only as a carried occurrence:

```text
appPolicy : CarriedRecordPolicy(S.T, ClosureApparatusRecord)

ClosureApparatusRecordCarriedAt(appPolicy, app.apparatusRecord,
    n0, sourceTag, generatedByS, inScope) :=
  CarriedRecordAt(appPolicy, app.apparatusRecord,
    n0, sourceTag, generatedByS, inScope).

ClosureApparatusOccurrenceFor(S, t, app) :=
  app.time = t
  and exists n0 sourceTag generatedByS inScope,
    ClosureApparatusRecordCarriedAt(
      appPolicy, app.apparatusRecord,
      n0, sourceTag, generatedByS, inScope)
  and CarriedInstrument(app.gateInstrument)
  and every record in app.thresholdRecords is carried by
      app.gateInstrument.instrumentRecordCarried
  and every entry in app.usedLedgerEntries is in S.Lambda_S.ledgerEntries
  and every auditRecord in app.usedAuditRecords has
      HasCarriedRecordEvidence(S.auditRecordPolicy, auditRecord).
```

This is occurrence-level, not value-level. Equal apparatus records may have different carried occurrences, source tags, or scopes; E3 credits the occurrence that actually enters the running package.

### Maintenance operator and reinstatement

E3's new carried object is the maintenance operator:

```text
structure ClosureMaintenanceOperator where
  operatorRecord : MaintenanceOperatorRecord
  apply : S.T.Z -> ClosureApparatus
  operatorLedgerEntries : List LedgerEntry
  operatorAuditRecords : List AuditRecord
```

It is carried by its own D3/D4 policy:

```text
maintenancePolicy : CarriedRecordPolicy(S.T, MaintenanceOperatorRecord)

MaintenanceOperatorCarriedAt(maintenancePolicy, m.operatorRecord,
    n0, sourceTag, generatedByS, inScope) :=
  CarriedRecordAt(maintenancePolicy, m.operatorRecord,
    n0, sourceTag, generatedByS, inScope).

MaintenanceOperatorOccurrenceFor(S, t, m) :=
  exists n0 sourceTag generatedByS inScope,
    MaintenanceOperatorCarriedAt(
      maintenancePolicy, m.operatorRecord,
      n0, sourceTag, generatedByS, inScope)
  and generatedByS = true
  and inScope = true
  and sourceTag in { committed_state, audited_cell_records }
  and every entry in m.operatorLedgerEntries is in S.Lambda_S.ledgerEntries
  and every auditRecord in m.operatorAuditRecords has
      HasCarriedRecordEvidence(S.auditRecordPolicy, auditRecord).
```

The maintenance operator is not credited merely because some operator-shaped value exists. A concrete reinstatement record must tie the operator, source state, input apparatus, output apparatus, and kernel transition together:

```text
structure MaintenanceReinstatementRecord where
  time : Nat
  sourceState : S.T.Z
  targetState : S.T.Z
  operatorRecord : MaintenanceOperatorRecord
  preAppRecord : ClosureApparatusRecord
  postAppRecord : ClosureApparatusRecord
  outputRecord : ClosureApparatusRecord
  reinstatementLedgerEntry : LedgerEntry
```

```text
reinstatementPolicy :
  CarriedRecordPolicy(S.T, MaintenanceReinstatementRecord)

MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record) :=
  ClosureApparatusOccurrenceFor(S, t, app_t)
  and ClosureApparatusOccurrenceFor(S, t+1, app_tplus1)
  and MaintenanceOperatorOccurrenceFor(S, t, m)
  and exists n0 sourceTag generatedByS inScope,
    CarriedRecordAt(reinstatementPolicy, record,
      n0, sourceTag, generatedByS, inScope)
  and sourceTag in { committed_state, audited_cell_records }
  and generatedByS = true
  and inScope = true
  and record.time = t
  and record.operatorRecord = m.operatorRecord
  and record.preAppRecord = app_t.apparatusRecord
  and record.postAppRecord = app_tplus1.apparatusRecord
  and record.outputRecord = (m.apply(record.sourceState)).apparatusRecord
  and app_tplus1 = m.apply(record.sourceState)
  and app_tplus1.apparatusRecord = (m.apply(record.sourceState)).apparatusRecord
  and record.reinstatementLedgerEntry in S.Lambda_S.ledgerEntries
  and S.T.suppK(record.sourceState, record.targetState).
```

The full-apparatus equality is load-bearing. E3 chooses the direct-equality discipline rather than introducing a separate certified record-determination predicate: the next apparatus must be exactly the closure apparatus produced by `m.apply(record.sourceState)`, including `gateInstrument`, `thresholdRecords`, `appBoundary`, and `auditData`, not merely the same `apparatusRecord` bookkeeping tag. This blocks the unlinked-evidence bug where a record tag is tied to the operator output but the concrete apparatus content is unrelated.

### Challenge-free fixed point and challenge repair

E3 needs a measured apparatus distance. Since no such metric exists in D1-D6, it is a certified host interface:

```text
structure ClosureApparatusDistance where
  distance : ClosureApparatus -> ClosureApparatus -> Rat
  nonnegative :
    forall app app', 0 <= distance(app, app')
  zeroOnSameRecord :
    forall app app',
      app.apparatusRecord = app'.apparatusRecord ->
        distance(app, app') = 0.
```

For a declared tolerance:

```text
epsilon : Rat

ApproxApparatusFixedPoint(distance, epsilon, app_t, app_tplus1) :=
  distance.distance(app_tplus1, app_t) <= epsilon.
```

Challenge-free steps and challenged apparatus-repair steps are separated:

```text
ChallengeFreeAt(H, t) : Prop
ClosureApparatusChallengeAt(H, C, t) : Prop
```

`ChallengeFreeAt` is a measured run predicate: no declared challenge episode binding the closure apparatus occurs at time `t`. `ClosureApparatusChallengeAt` is the apparatus-level analogue of E1's challenge class, not an object-level challenge to the current quotient.

Under challenge, E3 applies E1 at the apparatus level. This is not a bare re-run of E1 on the object quotient. The defect and repair package live in the closure apparatus:

```text
ApparatusDefectForChallenge(S, H, C, t, app_t, defect) : Prop
ApparatusRepairRefinement : Type

EndogenousRepairOccurrenceWithWitnesses(
    S, H, C, t, rho_t, R_t, z, z', defect, move, auditRecord) :=
  exists episode,
    episode in H.episodes
    and rho_t in H.repairAuditEntries
    and H.entryEpisode(rho_t, episode)
    and episode.challengeClass = C
    and episode.time = t
    and RepairTypedAuditEntryCarried(S, rho_t)
    and rho_t.entryClass.sourceTag = committed_state
    and rho_t.entryClass.generatedByS = true
    and rho_t.entryClass.inScope = true
    and move = S.R_S(defect)
    and rho_t = RepairTypedAuditEntry.move(
          move.moveRecord, rho_t.entryClass)
    and ESystem.RepairStep(S, z, z', defect, auditRecord)
    and CorePromotionGatesPass(S, z, z', defect, move, auditRecord)
    and installs.holds(move.payload, R_t)
    and postState.holds(z', episode).

ApparatusLevelRepairOccurrenceWithWitnesses(
    S, H, C, t, app_t, app_tplus1, m, record,
    rho_t, R_t, z, z', defect, move, auditRecord) :=
  MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record)
  and EndogenousRepairOccurrenceWithWitnesses(
        S, H, C, t, rho_t, R_t, z, z', defect, move, auditRecord)
  and R_t installs a repair of
    app_t.gateInstrument / app_t.thresholdRecords /
    app_t.appBoundary / app_t.auditData
  and ApparatusDefectForChallenge(S, H, C, t, app_t, defect).

ApparatusLevelRepairOccurrence(
    S, H, C, t, app_t, app_tplus1, m, record) :=
  exists rho_t R_t z z' defect move auditRecord,
    ApparatusLevelRepairOccurrenceWithWitnesses(
      S, H, C, t, app_t, app_tplus1, m, record,
      rho_t, R_t, z, z', defect, move, auditRecord).
```

The same occurrence supplies the E1 repair entry and the E3 reinstatement record. If the repair entry is fallback, off-kernel, or omitted from the audit history, the branch is subsidized or obstructed, not maintained.

For a maintenance step:

```text
ApparatusMaintainedStep(
    S, H, C, distance, epsilon, t, app_t, app_tplus1, m, record) :=
  MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record)
  and (
    ChallengeFreeAt(H, t)
      and ApproxApparatusFixedPoint(
            distance, epsilon, app_t, app_tplus1)
    or
    ClosureApparatusChallengeAt(H, C, t)
      and ApparatusLevelRepairOccurrence(
            S, H, C, t, app_t, app_tplus1, m, record)
  ).
```

The current apparatus and the next apparatus are explicitly scoped by time. Completeness predicates below only quantify over occurrences at the same time/horizon; a candidate `app_{t+1}` is not forced into the current `App_t` inventory before the maintenance step produces it. This is the E3 analogue of the current-versus-fresh scoping fix in E2.

### Object-level fixed point as certified F19/F20 input

F19/F20 object persistence is not mechanized in this repository. E3 follows E7's treatment of F19 and introduces certified predicates:

```text
ObjectLevelFixedPointCertified(S, H, t, horizon) : Prop
ObjectRecordCoherenceCertified(S, H, t, horizon) : Prop
ObjectLevelTransientPersistence(S, H, t, horizon) : Prop
```

`ObjectLevelFixedPointCertified` is the source text's `E_t^2 = E_t` up to defect, i.e. object-level closure/persistence. `ObjectRecordCoherenceCertified` is the F20-style carried record coherence side. E3 does not build F19's viability-kernel or F20's record-formation machinery locally.

The two-level condition is:

```text
ApparatusLevelFixedPointMaintained(
    S, H, C, distance, epsilon, t, horizon) :=
  exists app_t app_tplus1 m record,
    ApparatusMaintainedStep(
      S, H, C, distance, epsilon,
      t, app_t, app_tplus1, m, record).

TwoLevelFixedPoint(
    S, H, C, distance, epsilon, t, horizon) :=
  ObjectLevelFixedPointCertified(S, H, t, horizon)
  and ObjectRecordCoherenceCertified(S, H, t, horizon)
  and ApparatusLevelFixedPointMaintained(
        S, H, C, distance, epsilon, t, horizon).
```

The new content is the apparatus-level fixed point. Object-level persistence alone is `crystal-grade`, not maintained closure.

### E2 regress stop

If the maintenance operator or its auditing apparatus is itself audited, E2 controls the regress. E3 records the cross-reference using E2's actual landed declarations:

```text
E2AuditedRepairTriggerWitnessFor(
    S, H, C, horizon, t, rho_t, R_t, z, z', defect, move, auditRecord) :=
  ChallengedEpisodeTime(H, C, t)
  and EndogenousRepairOccurrence(S, H, C, t, rho_t, R_t)
  and rho_t in H.repairAuditEntries
  and move = S.R_S(defect)
  and ESystem.RepairStep(S, z, z', defect, auditRecord)
  and CorePromotionGatesPass(S, z, z', defect, move, auditRecord).

MaintenanceOperatorAuditedByTower(S, H, C, t, horizon, m, tower, n) :=
  MaintenanceOperatorOccurrenceFor(S, t, m)
  and exists app_t app_tplus1 record rho_t R_t z z' defect move auditRecord stack,
    MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record)
    and ApparatusLevelRepairOccurrenceWithWitnesses(
          S, H, C, t, app_t, app_tplus1, m, record,
          rho_t, R_t, z, z', defect, move, auditRecord)
    and E2AuditedRepairTriggerWitnessFor(
          S, H, C, horizon, t,
          rho_t, R_t, z, z', defect, move, auditRecord)
    and FIIIInstrumentStackBridge(S, tower, n, stack)
    and the tower's carried lower-stack audit records cite
          m.operatorRecord and record.

MaintenanceAuditRegressStoppedByE2(
    S, H, C, t, horizon, m, tower, n, measure, z, targetLevel) :=
  MaintenanceOperatorAuditedByTower(S, H, C, t, horizon, m, tower, n)
  and CapacityRealizableTower(S, tower, n)
  and E2_CapacityBound(S, measure, tower, n, z)
  and CompleteBoundedReflexivityStatus(
        S, H, C, tower, n, z, horizon, targetLevel)
  and the conclusion of E2_StatusPartition holds at targetLevel
  and for any same-level Sound(I) claim at targetLevel without a shift bridge,
        E2_SelfSoundnessObstruction applies.
```

This is not a new E3 proof that regress terminates by magic, and it is not a detached restatement of E2. `MaintenanceOperatorAuditedByTower` is the bridge: the E2 tower must be the tower auditing this maintenance operator's own apparatus-level repair/reinstatement occurrence. E2 then proves that this carried audit tower is finite-capacity and that same-level complete self-soundness is not accepted. E3's regress discipline is: the tower may rotate, saturate, or remain active-scoped, but it never reaches a final self-certified top level.

### Maintenance obstruction

The source obstruction is:

```text
Delta_maint(S, H, t, app_t, app_tplus1, component) :=
  component is a gate, threshold, AppBoundary, or audit-data component
    required for app_tplus1
  and (
    no carried MaintenanceReinstatementRecord accounts for component
    or the reinstatement record has sourceTag = fallback
    or sourceTag in { unknown, contradictory,
        independent_pair_witness, simulation_trace, ablation_record }
    or generatedByS = false
    or inScope = false
    or not MaintenanceOperatorOccurrenceFor(S, t, m)
    or not MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record)
    or the associated transition is not realized by S.T.suppK
    or the record is omitted from the complete challenge/audit history
  ).

DeltaMaintEmpty(S, H, t, app_t, app_tplus1) :=
  forall component,
    not Delta_maint(S, H, t, app_t, app_tplus1, component).
```

`Delta_maint` is the E3 analogue of E1's `Delta_endo`: a closure-apparatus reinstatement that works only through fallback, off-kernel, absent, or omitted evidence is not self-maintenance.

### Four-way status partition

E3's status set is:

```text
inductive MaintenanceClosureStatus
  | crystal_grade
  | maintained_closure
  | subsidized_closure
  | decaying_closure
```

The status record is carried:

```text
structure MaintenanceStatusRecord where
  time : Nat
  horizon : Horizon
  status : MaintenanceClosureStatus
  objectFixedPointRecord : ObjectFixedPointStatusRecord
  apparatusRecord : ClosureApparatusRecord
  maintenanceOperatorRecord : Option MaintenanceOperatorRecord
  reinstatementRecord : Option MaintenanceReinstatementRecord
  apparatusDistanceRecord : ApparatusDistanceRecord
  supportingLedgerEntries : List LedgerEntry
  supportingAuditRecords : List AuditRecord
```

```text
maintenanceStatusPolicy : CarriedRecordPolicy(S.T, MaintenanceStatusRecord)

MaintenanceStatusRecordCarriedAt(maintenanceStatusPolicy, record,
    n0, sourceTag, generatedByS, inScope) :=
  CarriedRecordAt(maintenanceStatusPolicy, record,
    n0, sourceTag, generatedByS, inScope).

MaintenanceStatusOccurrenceFor(S, H, t, horizon, record) :=
  record.time = t
  and record.horizon = horizon
  and exists n0 sourceTag generatedByS inScope,
    MaintenanceStatusRecordCarriedAt(
      maintenanceStatusPolicy, record, n0,
      sourceTag, generatedByS, inScope)
  and every entry in record.supportingLedgerEntries
      is in S.Lambda_S.ledgerEntries
  and every auditRecord in record.supportingAuditRecords
      has HasCarriedRecordEvidence(S.auditRecordPolicy, auditRecord).
```

`MaintenanceStatusOccurrenceFor` only checks that the status record is a genuine carried occurrence with carried support. Branch-specific case predicates below tie `reinstatementRecord` and `maintenanceOperatorRecord` to their concrete witnesses, because those witnesses are not in scope at the generic occurrence layer.

The branch evidence predicates are:

```text
ApparatusStableWithoutMaintenance(
    S, H, distance, epsilon, t, horizon) : Prop

ApparatusDecayExceedsTolerance(
    S, H, distance, epsilon, t, horizon) : Prop

ApparatusReinstatedByExternalCarrier(
    S, H, t, app_t, app_tplus1) : Prop

NoValidMaintenanceReinstatement(
    S, H, t, app_t, app_tplus1) : Prop
```

These are certified measured-run/status predicates. `ApparatusStableWithoutMaintenance` and `ApparatusDecayExceedsTolerance` must be complementary under the declared perturbation experiment; that complement is part of the host's status classifier, not silently derived from a scalar threshold without proof.

```text
SubsidizedReinstatementWitness(
    S, H, t, app_t, app_tplus1, maybeRR, component) :=
  Delta_maint(S, H, t, app_t, app_tplus1, component)
  and (
    (maybeRR = none
      and no carried MaintenanceReinstatementRecord accounts for component
    )
    or
    (exists rr,
      maybeRR = some rr
      and rr is the specific present-but-defective reinstatement record
          accounting for component
      and rr is fallback, off-kernel, out-of-scope, non-carried,
          externally generated, or omitted from the complete audit history
    )
  ).

CrystalGradeEvidence(S, H, C, distance, epsilon, t, horizon) :=
  ObjectLevelFixedPointCertified(S, H, t, horizon)
  and ObjectRecordCoherenceCertified(S, H, t, horizon)
  and not exists m,
    MaintenanceOperatorOccurrenceFor(S, t, m)
    and m accounts for ClosureApparatus at t
  and not exists app_t app_tplus1 m record,
    MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record)
  and not exists app_t app_tplus1 maybeRR component,
    SubsidizedReinstatementWitness(
      S, H, t, app_t, app_tplus1, maybeRR, component)
  and ApparatusStableWithoutMaintenance(
        S, H, distance, epsilon, t, horizon)
  and not ApparatusDecayExceedsTolerance(
        S, H, distance, epsilon, t, horizon).

MaintainedClosureEvidence(
    S, H, C, distance, epsilon, t, horizon,
    app_t, app_tplus1, m, record) :=
  TwoLevelFixedPoint(S, H, C, distance, epsilon, t, horizon)
  and ApparatusMaintainedStep(
        S, H, C, distance, epsilon, t,
        app_t, app_tplus1, m, record)
  and DeltaMaintEmpty(S, H, t, app_t, app_tplus1)
  and not exists bad_app_t bad_app_tplus1 maybeRR component,
    SubsidizedReinstatementWitness(
      S, H, t, bad_app_t, bad_app_tplus1, maybeRR, component)
  and if the maintenance operator is audited by a tower,
      MaintenanceAuditRegressStoppedByE2 holds for that tower.

SubsidizedClosureEvidence(
    S, H, C, distance, epsilon, t, horizon,
    app_t, app_tplus1, maybeRR, component) :=
  ObjectLevelFixedPointCertified(S, H, t, horizon)
  and SubsidizedReinstatementWitness(
        S, H, t, app_t, app_tplus1, maybeRR, component)
  and not exists m record,
    MaintainedClosureEvidence(
      S, H, C, distance, epsilon, t, horizon,
      app_t, app_tplus1, m, record).

DecayingClosureEvidence(S, H, C, distance, epsilon, t, horizon) :=
  ObjectLevelTransientPersistence(S, H, t, horizon)
  and not exists app_t app_tplus1 m record,
    MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, record)
  and not exists app_t app_tplus1 maybeRR component,
    SubsidizedReinstatementWitness(
      S, H, t, app_t, app_tplus1, maybeRR, component)
  and exists app_t app_tplus1,
    NoValidMaintenanceReinstatement(S, H, t, app_t, app_tplus1)
    and not ApparatusReinstatedByExternalCarrier(
          S, H, t, app_t, app_tplus1)
    and ApparatusDecayExceedsTolerance(
          S, H, distance, epsilon, t, horizon)
    and not ApparatusStableWithoutMaintenance(
          S, H, distance, epsilon, t, horizon).
```

`CrystalGradeEvidence` and `DecayingClosureEvidence` keep internal existential checks because their status records store no positive reinstatement witness (`record.reinstatementRecord = none`). They are still made explicit: crystal-grade excludes both valid and subsidized reinstatement and excludes apparatus decay; decaying excludes valid reinstatement, external/subsidized reinstatement, and challenge-free stability. Maintained and subsidized evidence take their concrete witnesses as parameters so the case predicates can tie those witnesses to the status record fields. `SubsidizedReinstatementWitness` is `Option`-shaped: `none` records the absent-record obstruction, while `some rr` records a specific present-but-defective reinstatement record. Subsidized and decaying cases set `record.maintenanceOperatorRecord = none`: defective, fallback, or absent maintenance is not credited as a genuinely carried maintenance operator, even when `Delta_maint` mentions an operator-shaped value. Pairwise exclusivity is closed at the evidence level: crystal-grade excludes maintained and subsidized witnesses and excludes decaying by `not ApparatusDecayExceedsTolerance`; maintained excludes subsidized witnesses globally and carries a valid reinstatement; subsidized carries a `SubsidizedReinstatementWitness`; decaying globally excludes both valid and subsidized reinstatement and excludes crystal-grade stability.

Each branch is then tied to a concrete status record:

```text
CrystalGradeCase(S, H, C, distance, epsilon, t, horizon, record) :=
  MaintenanceStatusOccurrenceFor(S, H, t, horizon, record)
  and record.status = crystal_grade
  and record.reinstatementRecord = none
  and record.maintenanceOperatorRecord = none
  and CrystalGradeEvidence(S, H, C, distance, epsilon, t, horizon).

MaintainedClosureCase(S, H, C, distance, epsilon, t, horizon, record) :=
  MaintenanceStatusOccurrenceFor(S, H, t, horizon, record)
  and record.status = maintained_closure
  and exists app_t app_tplus1 m rr,
    record.reinstatementRecord = some rr
    and record.maintenanceOperatorRecord = some m.operatorRecord
    and MaintenanceReinstatementFor(S, H, t, app_t, app_tplus1, m, rr)
    and MaintainedClosureEvidence(
          S, H, C, distance, epsilon, t, horizon,
          app_t, app_tplus1, m, rr).

SubsidizedClosureCase(S, H, C, distance, epsilon, t, horizon, record) :=
  MaintenanceStatusOccurrenceFor(S, H, t, horizon, record)
  and record.status = subsidized_closure
  and record.maintenanceOperatorRecord = none
  and exists app_t app_tplus1 maybeRR component,
    record.reinstatementRecord = maybeRR
    and Delta_maint(S, H, t, app_t, app_tplus1, component)
    and SubsidizedClosureEvidence(
          S, H, C, distance, epsilon, t, horizon,
          app_t, app_tplus1, maybeRR, component).

DecayingClosureCase(S, H, C, distance, epsilon, t, horizon, record) :=
  MaintenanceStatusOccurrenceFor(S, H, t, horizon, record)
  and record.status = decaying_closure
  and record.reinstatementRecord = none
  and record.maintenanceOperatorRecord = none
  and DecayingClosureEvidence(S, H, C, distance, epsilon, t, horizon).
```

The complete classifier is:

```text
CompleteMaintenanceStatus(S, H, C, distance, epsilon, t, horizon) :=
  exists record,
    MaintenanceStatusOccurrenceFor(S, H, t, horizon, record)
    and (
      CrystalGradeCase(S, H, C, distance, epsilon, t, horizon, record)
      or MaintainedClosureCase(
           S, H, C, distance, epsilon, t, horizon, record)
      or SubsidizedClosureCase(
           S, H, C, distance, epsilon, t, horizon, record)
      or DecayingClosureCase(
           S, H, C, distance, epsilon, t, horizon, record)
    )
  and forall record1 record2,
    MaintenanceStatusOccurrenceFor(S, H, t, horizon, record1) ->
    MaintenanceStatusOccurrenceFor(S, H, t, horizon, record2) ->
    record1.status = record2.status.
```

This mirrors E1/E2/E7: existence must supply a branch-valid record, and uniqueness ranges over every genuine status occurrence for the same time and horizon. It is not a proof that arbitrary hosts expose an honest classifier.

```text
Theorem E3_TwoLevelFixedPoint:
```

The object-level fixed point is the certified F19/F20 part. The carried `statusRecord` hypothesis is required for the second conjunct: `MaintainedClosureHolds` is a carried-status claim, and the carriedness of the concluding status record cannot be derived from object fixedness, maintenance reinstatement, or apparatus repair alone. The no-subsidized-witness and conditional E2-regress-stop clauses are the evidence-side obligations already built into `MaintainedClosureEvidence`.

### Ablation separation falsifier

Let:


These are toy-lab/measured-run predicates, not pure D4 structure. `PersistentPerturbationExposure` certifies that the run genuinely exposes the closure apparatus to sustained perturbation over the relevant horizon, matching the source text's ablation framing. The registered falsifier is:

```text
Theorem E3_AblationSeparation:
```

If the maintenance channel is cut and the apparatus-decay curve does not separate from the object-level curve, the claimed maintained-closure instance is falsified and should be reclassified as `crystal_grade` or as a failed/underspecified experiment. This theorem target is likely Lean-shaped only after the toy-lab supplies concrete measured-curve predicates; the numerical separation itself is a step-4 empirical/sweep obligation.

Any nonempty `Delta_maint` defeats a `maintained_closure` claim. If the apparatus is reinstated but the reinstatement is fallback, off-kernel, out of scope, non-carried, or omitted from the complete audit history, the correct branch is `subsidized_closure`, not maintained closure.

A nonempty falsifier says the instance was not maintained closure as claimed; it was crystal-grade, subsidized, decaying, or the measurement predicates were not honestly instantiated.

## 3. Proof Spine

1. **Object persistence is certified, not derived.** Use `ObjectLevelFixedPointCertified` and `ObjectRecordCoherenceCertified` for the F19/F20 side. This is exactly the E7 precedent for F19: the local Lean file will not import the unvendored meta-math F19/F20 development.

2. **The closure apparatus is a carried D4 object.** `ClosureApparatusOccurrenceFor` checks the apparatus record, instrument records, threshold records, ledger entries, and audit records against D3/D4 carriedness. A closure apparatus cannot be credited by being named in prose or by being stored in a caller-provided list.

3. **The maintenance operator is carried separately.** `MaintenanceOperatorOccurrenceFor` gives the operator its own source and carriedness. This avoids collapsing the apparatus state and its reinstating operator into one unconstrained `Prop`.

4. **Reinstatement ties all witnesses together.** `MaintenanceReinstatementFor` relates `app_t`, `app_tplus1`, `m`, `record.sourceState`, `m.apply(record.sourceState)`, the carried reinstatement record, the ledger entry, and the D4 kernel transition. It requires `app_tplus1 = m.apply(record.sourceState)`, so the gate instrument, thresholds, `AppBoundary`, and audit data are tied directly to the operator output, not merely to a matching apparatus-record tag. This is the main anti-unlinked-evidence guard.

5. **Challenge-free dynamics are approximate fixed points.** When `ChallengeFreeAt(H,t)` holds, the apparatus-level condition is `distance(app_tplus1, app_t) <= epsilon`. The distance interface is certified host data; E3 does not invent a universal metric over arbitrary apparatus records.

6. **Challenge dynamics are E1 at the apparatus level.** When `ClosureApparatusChallengeAt(H,C,t)` holds, the apparatus defect must be discharged through E1's `EndogenousRepairOccurrence`, `ESystem.RepairStep`, and `CorePromotionGatesPass`, but the repair payload targets gates, thresholds, `AppBoundary`, or audit data. This is not object-level source repair of the current quotient.

7. **`Delta_maint` separates maintained from subsidized.** A fallback/off-kernel/out-of-scope/non-carried/omitted reinstatement may keep the apparatus running, but it is not self-maintenance. It is `subsidized_closure`.

8. **Status exactness uses an occurrence-complete classifier.** `CompleteMaintenanceStatus` supplies one branch-valid carried status record and uniqueness across all genuine carried status occurrences for the same `(S,H,t,horizon)`. Constructor disjointness then gives exactly one of four statuses.

9. **Branch exclusivity is substantive, not tag-only.** `maintained_closure` requires `DeltaMaintEmpty` and a valid carried reinstatement; `subsidized_closure` requires a nonempty `Delta_maint` style reinstatement and excludes maintained closure; `decaying_closure` requires no valid or subsidized reinstatement plus apparatus decay; `crystal_grade` requires object persistence, no carried maintenance, and apparatus stability without maintenance.

10. **The ablation claim is a falsifier discipline.** Cutting `m` should separate apparatus decay from object decay in a maintained-closure instance. This will be tested in the Repair-World toy lab; the Lean statement should treat the measured curves as certified predicates unless the Python model supplies a concrete finite curve type.

11. **E2 stops regress.** If maintaining `m` requires an audit tower, `MaintenanceOperatorAuditedByTower` ties that tower to the same apparatus-level maintenance occurrence. E2 then applies: `E2_ForcedStratification` rotates rather than self-certifies, `E2_CapacityBound` bounds the tower, and `E2_SelfSoundnessObstruction` blocks same-level accepted self-soundness. E3 does not prove a new infinite-regress theorem; it cites the already-landed E2 mechanism for this bridged tower.

12. **Current/fresh scoping is explicit.** Apparatus occurrence completeness is scoped by time. A current apparatus at `t` and a candidate output at `t+1` are not both forced into the same current inventory. This avoids the E2 v17-style inconsistency between current completeness and fresh extension witnesses.

## 4. Case Enumeration

1. **Maintained closure, challenge-free.** The object-level fixed point is certified; `app_t` and `m` are carried; `app_{t+1}=m(z_t)` is carried; the reinstatement record names the same operator and output; the D4 transition is kernel-realized; and `distance(app_{t+1},app_t) <= epsilon`.

2. **Maintained closure, challenged.** A closure-apparatus challenge occurs. The same carried reinstatement record is paired with an E1 endogenous repair occurrence whose defect and refinement are apparatus-level. `Delta_maint` is empty, and E2 bounds any audit tower used to audit the maintenance operator.

3. **Crystal-grade closure.** The object-level fixed point persists and the apparatus remains stable without a carried maintenance operator or reinstatement record. This is not E3 maintained closure; it is the crystal case from the source text.

4. **Subsidized closure.** The apparatus is reinstated, but the reinstatement is fallback, off-kernel, out of scope, generated outside `S`, non-carried, or omitted from the complete audit history. The apparatus may function, but the source of maintenance is external.

5. **Decaying closure.** Object-level persistence may transiently remain, but the apparatus drifts beyond `epsilon` under perturbation and no valid carried or subsidized reinstatement accounts for the drift.

6. **Absent reinstatement record.** A required gate/threshold/`AppBoundary`/audit-data component appears in `app_{t+1}`, but no carried `MaintenanceReinstatementRecord` ties it to `m(z_t)`. This is in `Delta_maint`.

7. **Off-kernel maintenance.** A maintenance record exists and even names the right operator, but there is no `S.T.suppK(sourceState,targetState)` transition. The branch is obstructed or subsidized, not maintained.

8. **Fallback maintenance.** A record with `sourceTag = fallback` reinstates the apparatus. This is explicitly `subsidized_closure`.

9. **Unlinked output evidence.** A carried operator exists and a carried next apparatus exists, but the reinstatement record does not prove `app_tplus1 = m.apply(record.sourceState)` and does not tie its `operatorRecord`, `preAppRecord`, `postAppRecord`, and `outputRecord` to that same full apparatus output. The case predicate fails.

10. **Maintenance regress attempt.** The host claims `m` is fully certified by itself at the same level. E2 rejects same-level accepted self-soundness and forces rotating/saturated/active-scoped status through a finite tower.

11. **Ablation separation pass.** Cutting `m` causes apparatus decay while object-level persistence initially remains. This supports `maintained_closure` rather than `crystal_grade`.

12. **Ablation separation fail.** Cutting `m` does not separate apparatus and object decay curves under persistent perturbation. The claimed maintained-closure instance is falsified or the perturbation/measurement setup is incomplete.

13. **Future sweep guard.** The toy-lab implementation must compute apparatus distance, object/apparatus curves, status classification, and `Delta_maint` from carried records and transitions. It must not hardcode the four statuses or pass/fail rows from the pre-registration.
