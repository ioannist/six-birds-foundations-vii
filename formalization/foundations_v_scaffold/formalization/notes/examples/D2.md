# D2 - Predictive Surplus, Quantified

**Source text:** THEOREMS.md §1.2, D2.  
**Target Lean module:** `SixBirdsFoundationsV.Definitional.PredictiveSurplus`.  
**Grounding:** Foundations III Theorem 8 (`FiniteMarkovClosureDeficit`) supplies the closure-deficit quantity on the finite Markov host. The Xi companion supplies the adequacy residual, chain rule, same-family saturation, and data-processing laws for operator laboratories.

## 1. Setup

D2 replaces the brainstorm's undeclared scalar `S(Q,M)` with an audited comparison made inside one of two declared laboratory types.

### Closure-deficit laboratory

Fix a finite Markov host in the sense of Foundations III Theorem 8:

```text
X          finite state carrier
P          finite stochastic kernel on X
mu         fixed distribution
tau        finite time lag
Q : X -> Y finite abstraction / quotient
L_tau      declared KL predictive closure loss
K_adm      declared admissible class of macro kernels on Y
```

For such a quotient `Q`, the closure deficit

```text
CD_tau(Q)
```

is the minimum predictive closure loss over the declared admissible macro kernels. Foundations III Theorem 8 identifies this value, under its finite-host assumptions, with the conditional-mutual-information shaped quantity

```text
I(X_t ; Q(X_{t+tau}) | Q(X_t)).
```

The vendored Lean anchor for this is `FiniteMarkovClosureProfile` and `finite_markov_closure_deficit`: the score type is abstract and carries `zero`, `add`, and `leq`, but no subtraction operation.

To compare two quotients `Q` and `M`, they must live on the same finite Markov host, with the same `tau`, the same predictive-loss convention, and compatible admissible-kernel declarations. D2 is not a comparison between unrelated closure-deficit ledgers.

### Operator / Xi laboratory

In an operator laboratory, fix:

```text
C        native currency / energy block
L_Q      native family associated with quotient or readout Q
D        declared dissolving-family readout
KLLdagger an explicit Moore-Penrose pseudoinverse witness for K_LL
```

The Xi companion defines the adequacy residual

```text
Xi_C(D | L_Q) = K_DD - K_DL K_LL^dagger K_LD
```

as a finite rational matrix. It is an operator residual: the part of the dissolving family `D` not explained by the native family `L_Q`. In the vendored Lean substrate, this route has concrete matrix subtraction and a trace operation `traceMat`; it also has `traceMat_sub` and `loewnerLE_traceMat_mono`.

The Moore-Penrose inverse is a supplied parameter in the current Lean substrate. D2 must therefore treat `KLLdagger` and the algebraic hypotheses that make it legal as part of the laboratory data, not as something computed internally.

## 2. Definition

D2 defines predictive surplus only after a comparison baseline has been declared.

### Closure-deficit formulation

An admissible closure-deficit surplus datum consists of:

```text
Q, M            comparable quotients on the same host
CD_tau          closure-deficit assignment for the declared tau/loss/admissible class
leq             score preorder
baseline_le     leq (CD_tau M) (CD_tau Q)
```

The order-level surplus assertion is

```text
S_tau(Q || M) >= 0    means    CD_tau(M) <= CD_tau(Q).
```

This is the primary Lean-friendly definition because the existing FIII score profile does not supply subtraction. In a numeric score host with a subtraction operation compatible with the order, the displayed formula in THEOREMS.md is the numerical representative:

```text
S_tau(Q || M) := CD_tau(Q) - CD_tau(M),
0 <= S_tau(Q || M) iff CD_tau(M) <= CD_tau(Q).
```

Thus the formula `CD_tau(Q) - CD_tau(M) >= 0` is not licensed for every abstract FIII `Score`; it is a specialization of the order-level comparison to a score type with subtraction.

The baseline `M` is intended to be surplus-free or no-worse relative to `Q` for the declared futures. Typical admissible cases are:

- `M` is exact for the declared future family, so `CD_tau(M) = 0`;
- `M` is an audited refinement or upgraded package whose data-processing proof gives `CD_tau(M) <= CD_tau(Q)`;
- `M` is a recognized baseline supplied by a source paper or toy laboratory with the comparison proof recorded.

The inequality is not automatic from the existence of `Q` and `M`.

### Xi-trace formulation

In an operator laboratory, the surplus readout is:

```text
S_Xi(Q; D) := traceMat (Xi_C(D | L_Q)).
```

This is a definitional alternative for the operator-lab setting, not a literal theorem asserting

```text
CD_tau(Q) - CD_tau(M) = traceMat (Xi_C(D | L_Q))
```

across different hosts. The two formulations play the same role: they quantify the declared leftover predictive/dissolving content after the current native quotient or family has done its explanatory work.

When an operator baseline `M` is part of the same Xi laboratory, the comparison form is:

```text
traceMat (Xi_C(D | L_M)) <= traceMat (Xi_C(D | L_Q)).
```

If `M` is exact adequate for `D`, then `Xi_C(D | L_M) = 0`, and the single residual trace `traceMat (Xi_C(D | L_Q))` is the surplus above the surplus-free baseline. If a numeric traced gap is required, it is:

```text
traceMat (Xi_C(D | L_Q)) - traceMat (Xi_C(D | L_M)),
```

using the matrix route's actual subtraction and the existing `traceMat_sub` lemma.

Minimal later-Lean declarations should therefore separate:

- an order-level closure-deficit predicate, e.g. `PredictiveSurplusNonnegative`;
- a numeric closure-deficit value only for score types with subtraction;
- an Xi trace readout for matrix laboratories;
- bridge hypotheses, if any, that relate a closure-deficit datum to an Xi datum.

## 3. Proof Spine

The nonnegativity claim is conditional, not automatic.

For the FIII closure-deficit route, `finite_markov_closure_deficit` proves what each `CD_tau(Q)` is: a minimum predictive closure loss, equal to the conditional-mutual-information shaped score for that quotient. It does not compare two arbitrary quotients. Therefore D2's nonnegative surplus statement requires a baseline comparison:

```text
CD_tau(M) <= CD_tau(Q).
```

Once that comparison is supplied, the order-level statement is immediate by definition. In a numeric score host, `0 <= CD_tau(Q) - CD_tau(M)` follows from the usual ordered-subtraction law. This law is not present in `FiniteMarkovClosureProfile`, so it must not be assumed in the abstract FIII formalization.

What can supply `CD_tau(M) <= CD_tau(Q)`?

1. **Exact baseline:** if `M` closes the declared future family exactly, then `CD_tau(M) = 0`. Since closure deficits are nonnegative in the finite KL host, `0 <= CD_tau(Q)`, so `CD_tau(M) <= CD_tau(Q)`.
2. **Data-processing / refinement proof:** if `M` is an audited upgrade of `Q` and the imported data-processing discipline applies to the declared future family, then the proof obligation is exactly that the upgraded package cannot have larger declared deficit. This is the condition that later E-laws must cite, not infer silently.
3. **Xi chain-rule proof:** in an operator laboratory, extending the native family from `L` to `L+ = [L;M]` gives

   ```text
   Xi_C(D | L+) = Xi_C(D | L) - positive Schur term,
   Xi_C(D | L+) <= Xi_C(D | L)
   ```

   in Loewner order. Applying trace monotonicity gives the scalar order

   ```text
   traceMat (Xi_C(D | L+)) <= traceMat (Xi_C(D | L)).
   ```

   Same-family saturation is the zero-improvement case: if the added family is already generated by `L`, the residual is unchanged.

The critical caveat is that source refinement by itself does not prove improvement. Foundations III explicitly records that package refinement is not assumed to improve any closure deficit, and its countermodel atlas includes examples where refinement worsens closure status for a given update. D2 therefore does not define `S_tau(Q || M) >= 0` for arbitrary `Q,M`; it defines the lawful surplus datum as the gap together with the comparison hypothesis or imported monotonicity proof that makes the gap nonnegative.

The Xi route is easier to mechanize numerically because the vendored matrix substrate has subtraction, `traceMat_sub`, Loewner order, and trace monotonicity. The FIII route should initially be mechanized as an order predicate over `Score.leq`, with numerical subtraction added only for concrete score types such as rational traces.

## 4. Case Enumeration

- **Identical baseline:** if `Q` and `M` are the same quotient presentation, or fiber-equivalent presentations with the same declared deficit ledger, then `CD_tau(Q) = CD_tau(M)` and the surplus is zero. In Xi form, if `L_Q = L_M`, the residual traces are equal.
- **Exact closure baseline:** if `M` is exact for the declared future family, then `CD_tau(M) = 0` and the surplus of `Q` against `M` is just `CD_tau(Q)` in numeric hosts.
- **Certified improving refinement:** if `M = Q vee R` and the declared data-processing proof applies, then `CD_tau(M) <= CD_tau(Q)`. The surplus is the certified deficit discharged by installing `R`.
- **Uncertified refinement:** if `M = Q vee R` but no data-processing or closure-improvement proof is recorded, D2 assigns no nonnegative surplus claim. Refinement can add distinctions without improving the declared closure deficit.
- **Same-family Xi saturation:** if an added operator family is already generated by the current native family, the Xi residual is unchanged; surplus discharged by that addition is zero.
- **Traceable positive residual:** if `Xi_C(D | L_Q)` is positive semidefinite and nonzero, then `traceMat (Xi_C(D | L_Q))` is a nonnegative scalar residual. This is a valid operator-lab surplus readout, not a proof that a corresponding Markov closure-deficit gap has been constructed.
- **Incomparable ledgers:** if `Q` and `M` use different time lags, different declared future families, different admissible classes, or unrelated currencies, then `S_tau(Q || M)` is undefined until a bridge aligns the ledgers.

## 5. Interaction Status

D2 does not duplicate FIV F2. F2 supplies the descent-repair normal form: when a readout fails to descend, one canonical repair is source refinement. D2 supplies a quantitative ledger for declared leftover predictive or dissolving content before and after such a repair. F2 says what kind of repair may be lawful; D2 says how a declared surplus gap is measured once the closure-deficit or Xi laboratory has been fixed.

D2 interacts with D1 because downstream repairs often take the form `Q |-> Q vee R`. D1 supplies the common-refinement operation. D2 adds the separate requirement that the refinement be accompanied by a closure-deficit or Xi monotonicity proof before any nonnegative surplus-discharge claim is made.

The named FIV data-processing anchor is F6 No-Needles Stability. F6's proof uses Loewner monotonicity under declared residual and transport budgets, and its layer instantiations explicitly include Lindblad-Uhlmann monotonicity and Csiszar `f`-divergence data-processing. D2 reuses that discipline in scalar/order form, while the more specific operator details come from the Xi companion's chain rule, native coarsening, exact bridge, and defective bridge results.

D2 also touches F7 Sufficiency Closure: the future family is declared, not universal. A quotient can have zero surplus only relative to the declared future/dissolving family currently in scope. It does not become sufficient for undeclared futures.

Under the anti-reductionism discipline, D2 is a map-and-audit definition. It does not reduce predictive surplus to one universal scalar. It records which already-audited deficit calculus is being used, what comparison baseline is declared, and what monotonicity proof makes the comparison lawful.

## 6. Nonclaims

- D2 does not assert that the brainstorm scalar `S(Q,M)` existed in the prior corpus.
- D2 does not define a universal surplus scalar across all hosts. It defines comparable surplus data inside declared closure-deficit or Xi laboratories.
- D2 does not assert `CD_tau(Q) - CD_tau(M)` in an abstract `Score` type without subtraction. The order statement `CD_tau(M) <= CD_tau(Q)` is primary there.
- D2 does not assert that every refinement lowers closure deficit. A D1 repair join needs an additional data-processing, exactness, or source-grounded comparison proof before it can be credited with surplus discharge.
- D2 does not identify the closure-deficit gap with `traceMat (Xi_C(D | L_Q))` as a cross-host equality. The Xi trace is a role-equivalent operator-lab readout unless a separate bridge theorem is supplied.
- D2 may use a stacked Xi family only inside an operator laboratory where the relevant native-family legality and admissibility hypotheses have already been declared. It does not certify that two access quotients admit an admissible joint access in the FIV F37 sense.
- D2 does not choose the declared future family, dissolving family, admissible macro-kernel class, or residual budget. Those are apparatus inputs.
- D2 does not claim that predictive surplus is the only useful measure of residual content; it is the Foundations V lawful measure for E-laws that say they collapse surplus.
- D2 does not use or introduce any biological or life-sciences content.
