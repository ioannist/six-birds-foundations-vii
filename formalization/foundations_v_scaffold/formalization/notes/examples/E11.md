# E11 - Institutional Rewrite Law (Stack Activity)

**Source text:** THEOREMS.md §3, E11.  
**Target Lean module:** `SixBirdsFoundationsV.Laws.E11InstitutionalRewrite`.  
**Grounding:** D3 supplies carried records and source classes; D4 supplies the lower-layer carrier, kernel support `S.T.suppK`, closure package fields, ledger, and carried instrument/audit surface; FIII supplies the vendored top-down channel record and NC-TD theorem in `SixBirdsIII.TopDownChannel`. Foundations I downward-influence trichotomy and the Institutions-paper material-forcing/washout facts are not vendored in this repo, so E11 treats those as certified/background inputs rather than local Lean dependencies.

## 1. Setup

Let

```text
S : ESystem ...
T := S.T
```

be a D4 E-system exposing the lower-layer state type `T.Z`, kernel support

```text
T.suppK : T.Z -> T.Z -> Prop
```

and closure/package data through `T.E`, `T.FormedPackage`, `S.I_S`, and `S.Lambda_S`.

E11 adds an institutional label/intervention layer above that lower carrier. The upper package is not credited merely because a macro description exists. It is credited only through a carried comparison between two admissible, matched institutional interventions and a FIII top-down channel record whose effect comparator is tied to the same comparison.

and well-formedness fields for finite comparator/threshold and nonclaim recording. E11 must not redefine these gates. It supplies the Foundations-V bridge saying that the FIII record's `effectGate` is the effect of this actual institutional comparison on the lower layer's support or closure.

The second theorem is E11's NC-TD obstruction: a structural downward path by itself is not an accepted top-down channel.

InstitutionalInterventionOccurrenceFor(S, theta) :=

    and CarriedRecordAt(interventionPolicy, theta.interventionRecord,

DistinctInstitutionalInterventions(theta_i, theta_j) :=
  theta_i.labelValue != theta_j.labelValue

### Matched-controls comparison

The law is about paired interventions, not arbitrary before/after anecdotes:

```text
structure MatchedInstitutionalComparison where
  comparisonRecord : MatchedComparisonRecord
  theta_i : InstitutionalIntervention
  theta_j : InstitutionalIntervention
  channelRecord : SixBirdsIII.TopDownChannelRecord
  matchedControlsRecord : AuditRecord
  controlledLowerContext : LowerContextRecord
  uncontrolledDifferenceWitness : Option UncontrolledDifferenceRecord
```

```text
MatchedControlsComparison(S, comparison) :=
  InstitutionalInterventionOccurrenceFor(S, comparison.theta_i)
  and InstitutionalInterventionOccurrenceFor(S, comparison.theta_j)
  and DistinctInstitutionalInterventions(
        comparison.theta_i, comparison.theta_j)
  and CarriedRecordAt(comparisonPolicy, comparison.comparisonRecord,
        n0, committed_state, true, true)
  and HasCarriedRecordEvidence(
        S.auditRecordPolicy, comparison.matchedControlsRecord)
  and comparison.uncontrolledDifferenceWitness = none
  and comparison.channelRecord.matchedControlsGate = true.
```

If `uncontrolledDifferenceWitness != none`, the comparison is not a valid E11 comparison. It may be an empirical row to debug, but it is not eligible for the status theorem.

The following are certified host predicates for the Institutions-paper washout/material-forcing boundary:

```text
structure StaticInstitutionalLabels where
  holds : MatchedInstitutionalComparison -> Prop

structure BaseIndependentBehavior where
  holds : MatchedInstitutionalComparison -> Prop

structure StrictInstitutionalRefinement where
  holds : MatchedInstitutionalComparison -> Prop
```

`StaticInstitutionalLabels` and `BaseIndependentBehavior` are positive washout facts. `StrictInstitutionalRefinement` is the strict lower predictive refinement that live labels can force; washout requires its negation.

The ambient certified washout interfaces are:

```text

baseIndependent : BaseIndependentBehavior

```

### Lower-layer structural comparators

E11 distinguishes lower-layer structure from transition probabilities. The support comparator is about reachability/admissibility classes, not probabilities:

```text
structure LowerKernelSupportComparator where
  supportUnder :
    InstitutionalIntervention -> S.T.Z -> S.T.Z -> Prop
  agreesWithCarrier :
    forall theta z z',
      supportUnder(theta,z,z') ->
        lower-layer transition z -> z' is admissible under theta
  finiteComparator : Prop
  finiteComparatorCertified : finiteComparator
```

```text
KernelSupportDiffers(comparator, theta_i, theta_j) :=
  exists z z',
    comparator.supportUnder(theta_i,z,z')
      != comparator.supportUnder(theta_j,z,z').
```

The closure comparator is about lower-layer closure, not weights:

```text
structure LowerClosureComparator where
  closureUnder :
    InstitutionalIntervention -> LowerClosureSignature
  finiteComparator : Prop
  finiteComparatorCertified : finiteComparator

ClosureDiffers(closureComparator, theta_i, theta_j) :=
  closureComparator.closureUnder(theta_i)
    != closureComparator.closureUnder(theta_j).
```

Parameter conditioning is recorded separately:

```text
structure LowerParameterComparator where
  parametersDiffer :
    InstitutionalIntervention -> InstitutionalIntervention -> Prop
  supportUnchanged :
    LowerKernelSupportComparator ->
      InstitutionalIntervention -> InstitutionalIntervention -> Prop
  closureUnchanged :
    LowerClosureComparator ->
      InstitutionalIntervention -> InstitutionalIntervention -> Prop

ParameterConditioningOnly(
    parameterComparator, supportComparator, closureComparator,
    theta_i, theta_j) :=
  parameterComparator.parametersDiffer(theta_i, theta_j)
  and parameterComparator.supportUnchanged(
        supportComparator, theta_i, theta_j)
  and parameterComparator.closureUnchanged(
        closureComparator, theta_i, theta_j)
  and not KernelSupportDiffers(
        supportComparator, theta_i, theta_j)
  and not ClosureDiffers(
        closureComparator, theta_i, theta_j).
```

This is the load-bearing line in E11: transition-probability or parameter differences are conditioning unless the support or closure comparator moves.

### FIII channel bridge

The channel bridge ties the same comparison, same FIII channel record, and same effect record to the structural comparator:

```text
TopDownChannelRecordCarriedAt(
    channelPolicy, channelRecord,
    n0, sourceTag, generatedByS, inScope) :=
  CarriedRecordAt(channelPolicy, channelRecord,
    n0, sourceTag, generatedByS, inScope).
```

```text
structure InstitutionalStructuralEffect where
  effectRecord : InstitutionalEffectRecord
  comparisonRecord : MatchedComparisonRecord
  channelRecord : SixBirdsIII.TopDownChannelRecord
  observedOutcome : InstitutionalOutcomeReadout
  supportWitness : Option (S.T.Z x S.T.Z)
  closureWitness : Option LowerClosureDifferenceRecord
```

```text
structure InstitutionalParameterEffect where
  parameterRecord : ParameterEffectRecord
  comparisonRecord : MatchedComparisonRecord
  observedOutcome : InstitutionalOutcomeReadout

ReproducesClaimedEffect(parameterEffect, structuralEffect) :=
  parameterEffect.observedOutcome = structuralEffect.observedOutcome.
```

`ReproducesClaimedEffect` compares the declared outcome/readout of the two experiments. It does not require the same support or closure witness, because the placebo comparison is purely parametric by construction.

```text
StructuralEffectFor(
    S, supportComparator, closureComparator,
    comparison, channelRecord, effect) :=
  MatchedControlsComparison(S, comparison)
  and comparison.channelRecord = channelRecord
  and effect.comparisonRecord = comparison.comparisonRecord
  and effect.channelRecord = channelRecord
  and CarriedRecordAt(effectPolicy, effect.effectRecord,
        n_effect, committed_state, true, true)
  and TopDownChannelRecordCarriedAt(
        channelPolicy, channelRecord,
        n0, committed_state, true, true)
  and SixBirdsIII.TopDownChannelAcceptedBool(channelRecord) = true
  and channelRecord.effectGate = true
  and (
    (exists z z',
      effect.supportWitness = some(z,z')
      and supportComparator.supportUnder(comparison.theta_i,z,z')
        != supportComparator.supportUnder(comparison.theta_j,z,z'))
    or
    (exists closureDiff,
      effect.closureWitness = some(closureDiff)
      and ClosureDiffers(
        closureComparator,
        comparison.theta_i, comparison.theta_j))
  ).
```

The equality `comparison.channelRecord = channelRecord` and the `effect.channelRecord = channelRecord` / `effect.comparisonRecord = comparison.comparisonRecord` conjuncts are deliberate anti-unlinked-evidence guards. A host cannot satisfy E11 using one accepted FIII record and a separate, unrelated support/closure inequality.

### Stack obstruction and E4 compilation interface

The source text defines:

```text
Delta_stack :=
  { claimed rewrites reproducible by parameter conditioning
    on the un-rewritten support }.
```

E11 makes this a counterfactual/placebo predicate over the claimed structural comparison and a separate independently carried parameter-only comparison:

```text
Delta_stack(
    S, parameterComparator, supportComparator, closureComparator,
    comparison, effect, parameterComparison, parameterEffect) :=
  MatchedControlsComparison(S, comparison)
  and effect.comparisonRecord = comparison.comparisonRecord
  and MatchedControlsComparison(S, parameterComparison)
  and parameterEffect.comparisonRecord =
        parameterComparison.comparisonRecord
  and CarriedRecordAt(parameterPolicy, parameterEffect.parameterRecord,
        n_parameter, committed_state, true, true)
  and ParameterConditioningOnly(
        parameterComparator, supportComparator, closureComparator,
        parameterComparison.theta_i, parameterComparison.theta_j)
  and ReproducesClaimedEffect(parameterEffect, effect).

DeltaStackEmptyFor(S, comparison, effect) :=
  not exists parameterComparison parameterEffect,
    Delta_stack(
      S, parameterComparator, supportComparator, closureComparator,
      comparison, effect, parameterComparison, parameterEffect).
```

The parameter comparison is independent of the claimed institutional comparison. It uses only parameter conditioning on unchanged support/closure and is a falsifier only if it reproduces the same declared observed outcome as the claimed structural effect. This makes `Delta_stack` a real alternative-explanation test rather than a contradiction against `StructuralEffectFor`.

The "constitutive" branch adds E4 compilation, but E4 has not landed. E11 therefore introduces a certified forward interface:

```text
structure E4CompiledInstitutionalRewrite where
  compiledRecordFor :
    MatchedInstitutionalComparison ->
    SixBirdsIII.TopDownChannelRecord ->
    InstitutionalStructuralEffect -> CompiledRewriteRecord
  holds :
    MatchedInstitutionalComparison ->
    SixBirdsIII.TopDownChannelRecord ->
    InstitutionalStructuralEffect -> Prop
```

This is a forward obligation, not a blocking dependency for the core E11 stack-active theorem:

```text
ForwardObligation(E4_constitutive_compilation_correspondence)
```

E11 can classify stack-active before E4 lands. It can classify constitutive only under this certified E4-shaped input.

## 2. Theorem + Obstruction Set

E11's status type is:

```text
inductive InstitutionalRewriteStatus where
  | inert
  | conditioning
  | stack_active
  | constitutive
```

A status record carries the comparison and support for the branch:

```text
structure InstitutionalRewriteStatusRecord where
  comparisonRecord : MatchedComparisonRecord
  status : InstitutionalRewriteStatus
  channelRecord : Option SixBirdsIII.TopDownChannelRecord
  effectRecord : Option InstitutionalEffectRecord
  parameterRecord : Option ParameterEffectRecord
  compiledRecord : Option CompiledRewriteRecord
  supportingLedgerEntries : List LedgerEntry
  supportingAuditRecords : List AuditRecord
```

```text
InstitutionalRewriteStatusOccurrenceFor(S, comparison, record) :=
  MatchedControlsComparison(S, comparison)
  and record.comparisonRecord = comparison.comparisonRecord
  and CarriedRecordAt(statusPolicy, record, n0,
        committed_state, true, true)
  and every entry in record.supportingLedgerEntries
      is in S.Lambda_S.ledgerEntries
  and every auditRecord in record.supportingAuditRecords
      has HasCarriedRecordEvidence(S.auditRecordPolicy, auditRecord).
```

The branch evidence predicates are:

```text
InertEvidence(
    S, parameterComparator, supportComparator, closureComparator,
    comparison) :=
  MatchedControlsComparison(S, comparison)
  and (
    WashoutNull(
      S, parameterComparator, supportComparator, closureComparator,
      comparison)
    or
    (
      not ParameterConditioningOnly(
        parameterComparator, supportComparator, closureComparator,
        comparison.theta_i, comparison.theta_j)
      and not exists channelRecord effect,
        StructuralEffectFor(
          S, supportComparator, closureComparator,
          comparison, channelRecord, effect)
    )).

ConditioningEvidence(
    S, parameterComparator, supportComparator, closureComparator,
    comparison, parameterEffect) :=
  MatchedControlsComparison(S, comparison)
  and parameterEffect.comparisonRecord = comparison.comparisonRecord
  and CarriedRecordAt(parameterPolicy, parameterEffect.parameterRecord,
        n_parameter, committed_state, true, true)
  and ParameterConditioningOnly(
        parameterComparator, supportComparator, closureComparator,
        comparison.theta_i, comparison.theta_j)
  and not exists channelRecord effect,
    StructuralEffectFor(
      S, supportComparator, closureComparator,
      comparison, channelRecord, effect).

ConstitutiveEvidence(
    S, supportComparator, closureComparator, e4Compiled,
    comparison, channelRecord, effect, compiledRecord) :=
  StructuralEffectFor(
    S, supportComparator, closureComparator,
    comparison, channelRecord, effect)
  and DeltaStackEmptyFor(S, comparison, effect)
  and e4Compiled.holds(comparison, channelRecord, effect)
  and CarriedRecordAt(compiledPolicy, compiledRecord,
        n_compiled, committed_state, true, true)
  and compiledRecord =
        e4Compiled.compiledRecordFor(
          comparison, channelRecord, effect).

ConstitutiveEvidenceExistsFor(S, ..., comparison) :=
  exists channelRecord effect compiledRecord,
    ConstitutiveEvidence(
      S, supportComparator, closureComparator, e4Compiled,
      comparison, channelRecord, effect, compiledRecord).

StackActiveEvidence(
    S, supportComparator, closureComparator, e4Compiled,
    comparison, channelRecord, effect) :=
  StructuralEffectFor(
    S, supportComparator, closureComparator,
    comparison, channelRecord, effect)
  and DeltaStackEmptyFor(S, comparison, effect)
  and not ConstitutiveEvidenceExistsFor(S, ..., comparison).
```

`StackActiveEvidence`'s exclusion of constitutive is comparison-wide, not scoped to its own local
`channelRecord`/`effect` witness. Excluding only `not e4Compiled.holds(comparison, channelRecord, effect)`
for the SAME `channelRecord`/`effect` this branch happens to pick would let a host satisfy
`StackActiveCase` and `ConstitutiveCase` simultaneously for one comparison using two different structural
effects (a non-compiled one for stack-active, a compiled one for constitutive). `ConstitutiveEvidenceExistsFor`
reuses `ConstitutiveEvidence` wholesale (not just `e4Compiled.holds`) so a compiled-but-`Delta_stack`-obstructed
or uncarried-compiled-record effect -- which does not itself satisfy `ConstitutiveEvidence` -- does not
wrongly block a separate, genuinely valid stack-active claim on the same comparison.

Pairwise exclusion is substantive:

```text
Inert_vs_Conditioning:
  WashoutNull includes not ParameterConditioningOnly,
  and the non-washout inert disjunct also includes
  not ParameterConditioningOnly.

Inert_vs_StackActive:
  InertEvidence excludes any StructuralEffectFor.

Conditioning_vs_StackActive:
  ConditioningEvidence requires not exists StructuralEffectFor.

StackActive_vs_Constitutive:
  StackActiveEvidence requires not ConstitutiveEvidenceExistsFor(comparison),
  a comparison-wide negation reusing ConstitutiveEvidence itself, while
  ConstitutiveEvidence requires e4Compiled.holds(...) for its own witnesses.
```

The status cases tie the carried record fields to those same witnesses:

```text
InertCase(S, comparison, record) :=
  InstitutionalRewriteStatusOccurrenceFor(S, comparison, record)
  and record.status = inert
  and record.channelRecord = none
  and record.effectRecord = none
  and record.parameterRecord = none
  and record.compiledRecord = none
  and InertEvidence(S, ..., comparison).

ConditioningCase(S, comparison, record) :=
  exists parameterEffect,
    InstitutionalRewriteStatusOccurrenceFor(S, comparison, record)
    and record.status = conditioning
    and record.channelRecord = none
    and record.parameterRecord = some(parameterEffect.parameterRecord)
    and record.effectRecord = none
    and record.compiledRecord = none
    and ConditioningEvidence(S, ..., comparison, parameterEffect).

StackActiveCase(S, comparison, record) :=
  exists channelRecord effect,
    InstitutionalRewriteStatusOccurrenceFor(S, comparison, record)
    and record.status = stack_active
    and record.channelRecord = some(channelRecord)
    and record.effectRecord = some(effect.effectRecord)
    and record.parameterRecord = none
    and record.compiledRecord = none
    and StackActiveEvidence(
      S, supportComparator, closureComparator, e4Compiled,
      comparison, channelRecord, effect).

ConstitutiveCase(S, comparison, record) :=
  exists channelRecord effect compiledRecord,
    InstitutionalRewriteStatusOccurrenceFor(S, comparison, record)
    and record.status = constitutive
    and record.channelRecord = some(channelRecord)
    and record.effectRecord = some(effect.effectRecord)
    and record.parameterRecord = none
    and record.compiledRecord = some(compiledRecord)
    and ConstitutiveEvidence(
      S, supportComparator, closureComparator, e4Compiled,
      comparison, channelRecord, effect, compiledRecord).
```

## 3. Proof Spine

1. **Validate the comparison.** `MatchedControlsComparison` first checks that both interventions are carried, distinct, admissible, source-valid, and matched on controlled lower context. If an uncontrolled difference witness is present, the comparison is not eligible for E11 status classification.

2. **Import FIII channel acceptance.** `TopDownChannelAcceptedBool(channelRecord) = true` is evaluated using the vendored FIII record, not a Foundations-V duplicate. FIII's `top_down_channel_implies_struct_down` supplies `StructDown(channelRecord)` from acceptedness.

3. **Tie the accepted channel to the effect comparator.** `StructuralEffectFor` requires the same `comparisonRecord` and same `channelRecord` in the comparison and effect record. This prevents the recurring unlinked-evidence bug: an accepted FIII channel and an unrelated support inequality cannot jointly prove stack-activity.

4. **Separate structure from parameters.** `KernelSupportDiffers` and `ClosureDiffers` are the only structural triggers. If only probabilities, weights, prices, or other lower parameters change while the support and closure signatures are unchanged, the branch is `conditioning`, not `stack_active`.

5. **Check `Delta_stack`.** If the claimed structural outcome is reproduced by a separate carried matched-controls parameter-only comparison on unchanged support and unchanged closure, `Delta_stack` is nonempty for the claimed comparison/effect. This falsifies the stack-active claim even if a macro intervention label is present.

6. **Stack-active follows from accepted channel plus structural effect.** With a valid comparison, accepted FIII channel, structural support or closure effect, and empty `Delta_stack`, the law classifies the upper package as stack-active unless the E4 compilation predicate also holds.

7. **Constitutive is stack-active plus E4 compilation.** Since E4 has not landed, E11 records `E4CompiledInstitutionalRewrite` as certified input and a forward obligation. The core stack-active theorem does not depend on E4.

8. **Washout is inert.** If labels are static/per-path and behavior is base-independent with no strict refinement, and the comparison is not a parameter-conditioning channel, the Institutions-paper washout certified predicate drives the inert branch.

9. **NC-TD is imported.** A structural downward path by itself is blocked, using `SixBirdsIII.structural_downward_influence_not_top_down_channel`. E11 never upgrades `StructDown` alone to `TopDownChannelAcceptedBool = true`.

10. **Status exactness uses occurrence-complete status records.** As in E1/E2/E3/E7, `CompleteInstitutionalRewriteStatus` supplies branch-valid existence and uniqueness over all genuine carried status occurrences for the same comparison. Constructor disjointness gives exactly one of the four statuses.

11. **Lucas-style descent failure is an instance, not a theorem premise.** The Lucas critique motivates the recognition source: macro laws fail to descend when the policy/institution layer rewrites agents' decision kernels. The Lean-shaped law only states the carried, matched-controls, support/closure rewrite normal form.

## 4. Case Enumeration

1. **Stack-active via support rewrite.** `MatchedControlsComparison` holds; `TopDownChannelAcceptedBool(channelRecord)=true`; `StructuralEffectFor` gives a support witness `(z,z')` where admissibility/reachability changes; `Delta_stack` is empty; E4 compilation is absent. The status is `stack_active`.

2. **Stack-active via closure rewrite with same support.** `KernelSupportDiffers` is false, but `ClosureDiffers` is true for the same comparison and same accepted channel record. The closure operator/signature changes, so the status is `stack_active`.

3. **Conditioning-only parameter channel.** Parameters, transition probabilities, prices, or intensities differ, but support and closure are unchanged. `ParameterConditioningOnly` holds and `StructuralEffectFor` does not. The status is `conditioning`.

4. **Inert macro-description.** A macro/institutional label is present, but there is no accepted FIII channel, no parameter-conditioning channel, and no support/closure rewrite. The status is `inert`.

5. **Constitutive rewrite.** The stack-active support/closure rewrite holds and `E4CompiledInstitutionalRewrite.holds(comparison, channelRecord, effect)` is certified. The status is `constitutive`. This branch is conditional on the E4 forward interface until E4 lands.

6. **Washout null.** Static, per-path labels with base-independent behavior produce no strict refinement, no parameter-conditioning channel, and no support/closure difference. The status is `inert`, not `conditioning` or `stack_active`.

7. **`Delta_stack` nonempty.** A claimed structural rewrite's observed outcome can be reproduced by an independent parameter-only comparison on un-rewritten support and unchanged closure. The claimed stack-active case is rejected; the parameter-only comparison may itself classify as `conditioning`.

8. **NC-TD control.** A structural path exists, but one or more FIII gates fail and `TopDownChannelClaimStatus = blocked`. This is not accepted top-down channel evidence. Cite `structural_downward_influence_not_top_down_channel`.

9. **Matched-controls failure.** The interventions differ in an uncontrolled respect. `MatchedControlsComparison` fails because `uncontrolledDifferenceWitness != none`; the status theorem is not applicable to that comparison.

10. **Unlinked effect evidence.** A FIII channel record is accepted for one comparison, while a support/closure inequality is measured for another comparison or stored in an effect record with a different `channelRecord`. `StructuralEffectFor` fails.

11. **Transition-probability near-zero tolerance.** A tiny nonzero probability change is not by itself a support change unless the declared support comparator's threshold/tolerance says the transition becomes admissible or inadmissible. The tolerance is certified before classification.

12. **Static institution with live-looking record.** A label record is carried and visible, but it is static and base-independent. It remains inert unless a matched intervention changes support or closure.

13. **Constitutive overclaim before E4.** A stack-active case is called "constitutive" without a certified E4 compilation record. It remains `stack_active`, not `constitutive`.

## 6. Nonclaims
