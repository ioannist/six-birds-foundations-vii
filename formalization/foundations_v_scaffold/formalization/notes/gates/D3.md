# D3 Gate And Null-Battery Record

**Unit:** D3 - Carried record and carried instrument
**Kind:** Definition / source-of-truth classification infrastructure
**Recorded:** 2026-07-03

D3 is a definition, but its subject matter is the visibility, audit, and
source-of-truth boundary itself. The visibility and audit gates therefore apply
more substantively than they did for D1/D2: they check whether D3's classifier
exposes and audits the records it uses, not whether D3 certifies every later
instrument or empirical claim.

## Promotion Gates

| gate | status | rationale |
| --- | --- | --- |
| suff | notRequired | D3 declares no future-probe family and makes no sufficiency claim. |
| desc | notRequired | D3 is not a descent-through-quotient theorem; it classifies whether records are system-carried. |
| stab | notRequired | D3 checks a declared trajectory segment but asserts no persistence, convergence, or stability result. |
| ctrl | notRequired | D3 has no intervention/control-channel certification claim; it only requires own-kernel support for the declared run segment. |
| nosmuggle | pass | D3 rejects fallback, off-scope, theorist-side, and off-kernel records; the contiguous `OwnKernelTraceTo` condition prevents hiding a tainted step by marking it out of scope. |
| vis | pass | D3's own classifier is legible: the fine source tags, carrier-coordinate predicate, contiguous trajectory witness, and carried-instrument record lists are explicit in the accepted Lean surface. |
| audit | pass | D3 directly reuses FIII audit/instrument vocabulary where available and has an accepted Lean mechanization of the fine-source predicate, contiguous trace guard, carried-record predicate, and carried-instrument list checks with no `sorry`/`admit`. |
| strict | notRequired | D3 is not a strict-promotion or nonfactorization claim. |
| locglob | notRequired | D3 asserts no local/global obstruction or globalization claim. |
