# D4 Gate And Null-Battery Record

**Unit:** D4 - Endogenous closure system, E-system
**Kind:** Definition / composite carried-loop infrastructure
**Recorded:** 2026-07-04

D4 is the first composite definition: formed package, carried instrument,
carried ledger, and carried repair generator are assembled into an active
detect -> repair -> re-audit loop. The control and audit gates therefore apply
substantively to D4's own construction. Stability still does not apply as a
success/convergence claim: D4 defines the lawful step shape, not persistence or
repair efficacy.

## Promotion Gates

| gate | status | rationale |
| --- | --- | --- |
| suff | notRequired | D4 declares no future-probe family and makes no sufficiency/factorization claim. |
| desc | notRequired | D4 is not a descent-through-quotient theorem; it packages the carried apparatus on which later descent/repair claims operate. |
| stab | notRequired | D4 defines a per-step detect/repair/re-audit loop but does not claim repairs persist, converge, succeed, or stabilize the system. |
| ctrl | pass | D4's `LawfulRepairStep` is a controlled repair channel: a move is lawful only with `GateAllows` projected from the active carried instrument `I_S`, admissibility, ledger budget-line membership, `suppK` realization, and re-audit projected from the same `I_S`. |
| nosmuggle | pass | The definition requires carried defect/audit records, a complete carried ledger, a carried instrument, P1-P5 repair sorts excluding P6, and own-kernel realization; repair availability is not inferred from a bare tuple. |
| vis | pass | The component boundaries are explicit in Lean: `TheoryPackage`, `CarriedLedger`, `RepairMove`, `LawfulRepairStep`, `RepairGeneratorStep`, and `ESystem` expose every certificate. |
| audit | pass | D4 makes re-audit a required field of `LawfulRepairStep` and has an accepted Lean mechanization with no `sorry`/`admit`; audit is active, not decorative. |
| strict | notRequired | D4 is not a strict-promotion, nonfactorization, or strict-extension theorem. |
| locglob | notRequired | D4 asserts no local/global obstruction or globalization claim. |
