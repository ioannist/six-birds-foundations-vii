# G7-L1 Prediction - Finite-Board Angel/Devil Search

## Hypothesis
On small finite `N x N` torus boards, exact bounded-horizon game-tree search will show a qualitative separation between `p=1` and `p=2`: power-1 angels are trapped within relatively few turns, while power-2 angels survive substantially longer within the tested horizons, for devil budgets `b in {1,2}`.

## Predicted Outcome
The minimax values are computed exactly by exhaustive memoized backward induction over `(angel position, deleted set, turns remaining)`. Memoization is allowed, but no sampling or heuristic pruning is used for the game value. Because a finite torus has only finitely many cells, "escape" in this lab means only "survives to the tested horizon," never permanent escape.

## Falsification Condition
If the exact sweep shows no meaningful trapped-time separation between `p=1` and `p=2` across the tested boards, or if `p=1` survives to comparable horizons while `p=2` is trapped at comparable settings, the expected finite-horizon calibration behavior is falsified.
