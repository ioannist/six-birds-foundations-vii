# G3-L1 Prediction - Amortized Calibration Battery

## Hypothesis
For binary-counter increment with `Phi = #1-bits`, every increment has exact
amortized cost `2`:

```text
a_hat_i = a_i + Phi(s_i) - Phi(s_{i-1}) = 2.
```

For dynamic-array insertion with `Phi = max(0, 2*size - capacity)`, every
insertion has amortized cost at most `3`, and resizing insertions have exact
amortized cost `3`.

For both calibrations, every finite operation sequence satisfies the exact
telescoping identity:

```text
sum a_i = sum a_hat_i + Phi(s_0) - Phi(s_n).
```

## Predicted Outcome
The identities and bounds hold exactly over seeded operation sequences of
length at least `1000` for each structure, using Python `int` arithmetic only.
No floats or approximate comparisons are used.

## Falsification Condition
Any single operation where the telescoping identity fails, where a binary
increment has amortized cost other than `2`, or where a dynamic-array insertion
has amortized cost greater than `3`, falsifies G3's theorem for that calibration
instance.
