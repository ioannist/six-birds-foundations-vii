# G13-L1 Prediction - Apollonian Curvature Census

## Hypothesis

This lab will generate exact-integer Apollonian curvature orbits for two root
Descartes quadruples:

- `(-1, 2, 2, 3)`, the baseline packing cited in `THEOREMS.md`.
- `(-6, 11, 14, 15)`, a different packing with the same mod-24 admissible
  type and a published reciprocity obstruction.

For `(-1, 2, 2, 3)`, the generated positive curvatures should lie in the
admissible residue classes `{2,3,6,11,14,15,18,23} mod 24`. The missing
admissible curvatures up to the computational bound are expected to be sparse;
this is only consistency with density-one behavior and the packing's still-open
local-global status, not a proof that the residual is finite or structured.

For `(-6, 11, 14, 15)`, the generated positive curvatures should again lie in
the same admissible residue classes, but no curvature of the form `2n^2`,
`3n^2`, or `6n^2` should appear. Those three families are the
literature-grounded reciprocity-obstructed families for this packing; this is
the hard falsifiable check in the lab.

## Predicted Outcome

All arithmetic will be exact integers. Every generated quadruple should satisfy
Descartes' identity exactly. The baseline packing should produce a finite
missing-admissible set at the selected bound without any claimed reciprocity
classification. The `(-6, 11, 14, 15)` packing should produce zero hits in the
`2n^2`, `3n^2`, and `6n^2` families for every family value within the selected
bound.

## Falsification Condition

Any generated quadruple violating Descartes' identity, any generated positive
curvature outside the expected mod-24 admissible classes, or any generated
curvature in the `2n^2`, `3n^2`, or `6n^2` reciprocity-obstructed families for
`(-6, 11, 14, 15)` falsifies this calibration run. A failure of the reciprocity
check would most likely indicate an implementation or citation-scoping bug and
must be reported prominently.
