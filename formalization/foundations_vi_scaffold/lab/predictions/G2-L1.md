# G2-L1 Prediction - Goodstein Ordinal Escrow

## Hypothesis
For hereditary base-`k` Goodstein steps, the ordinal assignment `O_k(n)` into
Cantor-normal-form trees below `epsilon_0` strictly descends after the Goodstein
decrement:

```text
O_{k+1}(G_k(n)) < O_k(n)
```

for every checked step of every run starting with `1 <= n <= 30` at base `2`.
Pure rebasing without the decrement is exactly stage-coherent:

```text
O_{k+1}(rebase_{k->k+1}(n)) = O_k(n).
```

## Predicted Outcome
Both identities hold exactly at every checked step, using only Python `int`
arithmetic and exact ordinal-tree comparison. No floats or approximate
comparisons are used.

## Falsification Condition
Any single checked step where the ordinal descent fails, or any checked pure
rebase where the ordinal-invariance identity fails, falsifies G2 Part (a)'s
stage-coherence audit for this calibration instance.
