# G12-L1 Prediction - Heule 826 Finite Witness

## Hypothesis

The vendored Heule/Polymath16 `826`-vertex unit-distance graph should verify as
a genuine finite witness for the G12 finite-witness schema:

- every one of the `4273` declared edges in `heule_826.edge` has exact squared
  Euclidean distance `1` when the coordinates in `heule_826.vtx` are parsed as
  exact algebraic SymPy expressions;
- a 4-coloring SAT encoding of the graph is UNSAT, so the graph is not properly
  4-colorable.

This is the 826-vertex Heule/Polymath16 intermediate graph documented in
`lab/foundations_vi_lab/g12_finite_witness/data/PROVENANCE.md`, not the current
smallest-known 509-vertex Parts graph. The provenance note records that the
smaller graph's raw coordinate data are not publicly archived in the same
coordinate-plus-edge form.

## Predicted Outcome

The unit-distance verification should pass in exact symbolic arithmetic and in
an independent high-precision numeric check. Random sampled non-edges should
not accidentally have exact squared distance `1`. The generated 4-coloring CNF
should have `3304` variables and `22874` clauses, and a modern PySAT solver
should report UNSAT.

## Falsification Condition

Any declared edge whose exact squared distance is not `1`, any structural parse
failure in the `826` vertices / `4273` edges input, or any satisfying 4-coloring
model from the SAT solver falsifies this lab. Because this is a previously
published witness stream, such a failure would most likely indicate a parsing,
data, or encoding bug in this reproduction, not a new mathematical discovery.

## Certificate Scope

The UNSAT determination is solver-verified, not independently proof-checked:
no public DRAT/resolution proof certificate is included in the vendored data,
and this lab does not attempt to produce or verify one.

## Correction Note (2026-07-07, post-run)

External review caught a provenance error in this prediction's framing and in
`data/PROVENANCE.md`: the claim that no public raw coordinate data exists for
smaller Heule/Polymath graphs was wrong. Heule's `github.com/marijnheule/
CNP-SAT` repository (missed by the original research pass, which checked only
his personal page and two other repos) publicly hosts `.vtx`/`.edge` data for
`510`/`517`/`529`/`553`/`610`/`633`/`803`/`826`/`874`, plus public DRAT proof
certificates for the `517`/`529`/`553`/`610`/`633`/`803` 4-coloring UNSAT
instances specifically (independently confirmed by the manager via the GitHub
API). The `826` instance used by this lab does not have a DRAT certificate in
that repository, so this correction does not change this lab's own outcome or
its "solver-verified, not proof-checked" scoping for the `826` graph — it
corrects only the broader claim that no such certificates exist anywhere in
this literature stream. See `data/PROVENANCE.md` for the full correction.
