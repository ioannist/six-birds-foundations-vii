# G8-L2 Prediction - Non-Abelian Separating Witness

## Hypothesis
The concrete case (b) system from the G8 Lean witness, with states `S`, `A`,
`B`, `N` and moves `r`, `s`, `p`, `q`, `t`, is terminating and confluent from
`S` but has route-dependent move counters.

## Predicted Outcome
Across at least 1000 seeded random legal orders from `S`, every run will reach
the normal form `N`. At least two sampled legal routes will have different
counter vectors, matching the Lean witness that confluence alone does not
produce a canonical odometer.

## Falsification Condition
If any sampled run reaches a stable state other than `N`, or if all sampled
runs share identical counter vectors, then the computational witness fails as a
sanity check of the case (b) separating example. The second condition is already
Lean-proved impossible for the displayed routes, so a failure there would point
to a lab implementation error or a mismatch with the Lean witness.

in this packet.
