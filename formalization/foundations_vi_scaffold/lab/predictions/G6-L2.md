# G6-L2 Prediction - Tunable Recaman Variants

## Variant A: Even-Jump Permanent Holes

Recurrence:

```text
a_0 = 0
candidate_n = a_{n-1} - 2n
a_n = candidate_n    if candidate_n > 0 and candidate_n is unused
a_n = a_{n-1} + 2n  otherwise
```

Hypothesis: every term `a_n` is even. Therefore every odd positive integer is
never visited and is a permanent hole. This should discharge the concrete
`DominantObstruction` hypothesis for any odd target `y`, with certificate time
`N = 0`.

## Variant B: Constant-Unit Full Coverage

Recurrence:

```text
a_0 = 0
candidate_n = a_{n-1} - 1
a_n = candidate_n    if candidate_n > 0 and candidate_n is unused
a_n = a_{n-1} + 1   otherwise
```

Hypothesis: `a_n = n` for every `n >= 0`, and after step `n` the visited set is
exactly `{0,1,...,n}`. Therefore every nonnegative integer is visited exactly
once. For any finite audit window `W = [1,M]`, the hole count is
`max(M-n,0)` at step `n`, so whenever it is positive the next step strictly
decreases it by one. This should discharge the concrete `DominantPressure`
hypothesis for each fixed window.

## Predicted Outcome

Exact integer simulation should verify both invariants over a large finite
prefix: all visited values even for Variant A, and exact identity/visited-set
equality for Variant B. The accompanying proof file should give the short
mathematical induction proofs that make the computational checks explanatory
rather than merely exploratory.

## Falsification Condition

Any odd value appearing in Variant A, or any step in Variant B with `a_n != n`
or visited set not exactly `{0,...,n}`, falsifies the corresponding prediction
and would require revising the proof.
