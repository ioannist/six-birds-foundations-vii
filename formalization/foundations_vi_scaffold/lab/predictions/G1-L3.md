# G1-L3 Prediction - Finite Ghost Toy

## Chosen Design
This lab uses the accelerated Collatz map on the finite residue ring
`Z/2^m` with `m = 16`. The native states are odd residues
`r in [1, 2^16)`, with the canonical integer order on representatives. For an
odd residue `r`, compute `s = (3*r + 1) mod 2^16`.

If `s != 0`, the finite residue determines `v2(s) < 16`, so the declared
native transition is `T_m(r) = s >> v2(s)`, again an odd residue. If `s == 0`,
the finite residue cannot determine the true valuation from the visible
`16` bits, so the declared transition goes to a special absorbing ghost state.
The explicit declared ghost residue is the unique odd solution of
`3*r + 1 == 0 mod 2^16`, namely `r = (2^16 - 1) / 3 = 21845`.

## Hypothesis
Every one of the `2^15 = 32768` odd residues is classified exhaustively as
one of:

1. descending before reaching the ghost state,
2. reaching the declared ghost state before any descent, or
3. entering a finite non-ghost bad cycle before any descent.

The expected shape is that most residues descend quickly, the declared ghost
residue accounts for the explicit ghost branch, and no non-ghost bad cycles
appear for `m = 16`.

## Predicted Outcome
The classification is total: zero unclassified residues and zero timeouts.
Relative to the characterized finite `Gamma_16` (the declared ghost residue,
plus any detected non-ghost bad cycles if they appear), the finite instance
discharges both G1 Part (b) hypotheses: ghost-bound residues never descend on
their checked finite trajectories, and all other residues have an explicit
separation witness `K = k*(r)` where they descend.

## Falsification Condition
Any odd residue that neither descends, reaches the declared ghost, nor enters a
detected cycle within the finite pigeonhole bound falsifies the classifier. A
non-ghost bad cycle would falsify the "no bad cycles expected" shape prediction
but not the lab's main goal, provided the cycle is explicitly reported as part
of `Gamma_16` and the classification remains exhaustive.

## Post-Run Correction Note - 2026-07-07

prediction "no non-ghost bad cycles appear" was false. The main finite-toy
goal survived: every odd residue was classified with zero unclassified cases,

`run.json`.
