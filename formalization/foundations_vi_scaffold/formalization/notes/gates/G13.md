**Unit:** G13 - Thin-Orbit Saturation
**Kind:** Schema-tier / imported-payload relative-density packaging, with an
Apollonian curvature-orbit calibration exhibit
**Recorded:** 2026-07-07

G13's Lean file proves only the elementary Nat-arithmetic packaging performed
on top of the imported thin-orbit saturation payload. The landed declarations
used for this panel are: `EventuallySublinear`, `EventuallyPositiveDensity`,
`EventuallyRelativelyNegligible`, `relative_density_theorem`,
`InfiniteFamily`, `ReciprocityCompatible`, and
`reciprocity_compatibility_observation`. Thin groups, spectral expansion,
Bourgain-Fuchs/Bourgain-Kontorovich density-one saturation, Apollonian
Descartes-reflection group actions, and the Haag-Kertzer-Rickards-Stange
reciprocity obstruction are explicitly imported instance content, not
reproduced in Lean.

The vendored `SixBirdsIII.Promotion` module supplies the nine gate fields and
status vocabulary: `GateStatus.pass`, `GateStatus.notRequired`,
`GateStatus.outsideScope`, and the corresponding `StrictGateStatus`
constructors for the strict gate. G13 is not packaged as one
`PromotionBridgeData` value, so this panel is scored manually against the
landed Lean declarations and lab artifacts, following the same convention used
by the G1-G11 and G4/G6 gate notes.

Scope note: G13-L1 is an exact-integer Apollonian curvature-orbit census for
two root quadruples, generated via Descartes reflections and bounded at
curvature `300000` (scaled down from the design spec's aspirational `10^6`
after disclosed feasibility probing). It uses `(-1,2,2,3)` (THEOREMS.md's own
cited baseline, the "bug-eye" packing) as an uncommitted clean-baseline
exhibit only — `61` admissible curvatures remain missing at this bound, an
open case-(iv) residual, NOT a reciprocity claim, since Haag-Kertzer-
Rickards-Stange's own Corollary 2.6 explicitly lists this packing as one of
the exceptions where the local-global conjecture may still hold. It uses
`(-6,11,14,15)` (the same admissible residue type, per the paper's Theorem
2.4, type `(8,11,-1)`) as the genuine, literature-verified case-(iii)
reciprocity-obstruction exhibit: Theorem 2.4 proves the families `2n^2`,
`3n^2`, `6n^2` never appear in that packing's orbit at all (the corresponding
false residue classes `2, 3, 6, 18 (mod 24)` are admissible per the congruence
audit; not every individual value of these families is itself admissible mod
24 — external review caught this exact imprecision, independently confirmed
by the manager: only half of each family's values land in an admissible
residue class), and the lab's exact-set-membership check over ALL family
values, not just the admissible subfamily, confirms zero hits up to the
computational bound — a valid, stronger-than-strictly-necessary consistency
check. The verdict correctly scopes this as a finite consistency check for
`reciprocity_compatibility_observation`, not a discharge of
`relative_density_theorem`'s imported hypotheses and not a reproof, extension,
or contradiction of the cited papers.
