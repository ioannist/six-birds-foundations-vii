## 2. Theorem → Lean target

Two **independent** schemas (unlike G1's coupled pair or G4's three-schema mix — G6's covering and
hole-forming schemas share no proof dependency). `covering_schema`: `DominantPressure holes` implies
every starting index eventually reaches a zero-hole index — proved via genuine well-founded/strong
induction (`Nat.strongRecOn`) on the current hole-count value, the first use of this technique since G2's
ordinal-descent machinery. `hole_forming_schema`: `DominantObstruction visited N` implies permanent
non-visitation for all `n≥N` — proved via ordinary structural induction. Both theorems are **fully
axiom-free**.

## 3. Proof spine → Lean target

`covering_schema`'s induction: for a state with hole-count `k`, either `k=0` (done) or
`DominantPressure` supplies a later index with a strictly smaller count, recursing via the induction
hypothesis at that smaller value. `hole_forming_schema`'s induction: base case is the hypothesis's own
`¬visited N`; inductive step chains the per-step propagation forward. The manager hand-traced both
proofs term-by-term and additionally constructed a fresh, independent concrete test instance (`holes n =
max(5-n, 0)`) to exercise `covering_schema` on genuine input beyond just reading the proof term.
