## 1. Setup → Lean target

`THEOREMS.md` §G13 "1. Setup" declares deep imported apparatus: an algebraic group `G` over `Q`, an
arithmetic lattice `G_Z`, a thin subgroup `Lambda < G_Z` acting on a discrete carrier `Y`, an orbit
`O = Lambda . x_0`, a projection `pi: O -> Z`, a positive-density target `A`, technical thinness
(`[H-G13-thin]`), a uniform spectral-gap expansion certificate (`[H-G13-expansion]`), a congruence-audit
target (`[H-G13-congruence-audit]`), and an imported exceptional-set bound (`[H-G13-imported-saturation]`).
None of this group-theoretic, spectral, or sieve-theoretic machinery is constructed in Lean —
`lean/SixBirdsFoundationsVI/Laws/G13ThinOrbitSaturation.lean` mechanizes only the elementary Nat-arithmetic
consequence performed on top of it. Three definitions carry the whole abstract content: `EventuallySublinear`
(`f`, in Nat-arithmetic form, is eventually `o(N)`: `∀k>0, ∃N0, ∀N≥N0, f N * k ≤ N`), `EventuallyPositiveDensity`
(`g` has an unconditional positive rational lower bound `c/k`: `∃c,k>0, ∀N, g N * k ≥ c * N`), and
`EventuallyRelativelyNegligible` (the target conclusion: `missed/total -> 0` in the same cross-multiplied
Nat-arithmetic style). This is a deliberately weaker, division-free rendering of the prose's
`O(N^{1-eta})` bound — `o(N)` is strictly implied by `O(N^{1-eta})` for any `eta>0`, and the conclusion
itself is only a qualitative ratio statement, not a rate, so nothing the abstract theorem actually needs
is lost.

**No Lean imports.** Standalone, like every prior law's file — confirmed by direct grep.

## 2. Theorem → Lean target

Two declarations, of sharply different weight. `relative_density_theorem` is the law's one genuine
derivation: `EventuallySublinear missed` plus `EventuallyPositiveDensity total` implies
`EventuallyRelativelyNegligible missed total`, via real constant-chasing Nat arithmetic (fix the target
scale `j`; extract density constants `c,k`; apply sublinearity at the scaled threshold `k*j`; rearrange by
associativity/commutativity; use `c≥1` to bound `N≤c*N≤total N*k`; chain; cancel the positive factor `k`
via `Nat.le_of_mul_le_mul_right`). `reciprocity_compatibility_observation` is deliberately light packaging
— `InfiniteFamily recip` plus `EventuallySublinear recip_count` trivially gives `ReciprocityCompatible
recip recip_count` (the conjunction `⟨hinf, hsub⟩`), recording only the observation that an infinite
reciprocity-obstructed family is compatible with, not contradicted by, a sublinear (hence density-zero)
count of that family. Both theorems are **fully axiom-free except** `relative_density_theorem`, which
depends only on `propext`.

## 4. Case enumeration → left as documentation

G13's two-level Case Enumeration (system-level: Saturated / Density-one-with-exceptional-set /
Positive-density-only / Undetermined; target-level: Congruence-obstructed / Hit / Reciprocity-obstructed /
Other-exceptional-uncertified) is an audit-record classification, not additional Lean structure. The
prose explicitly notes these tables "avoid the earlier axis-mixing failure": congruence-obstructed and
reciprocity-obstructed are disjoint by definition, since a reciprocity obstruction is recorded only after
a target has passed the congruence audit. G13-L1 is the first lab evidence for this taxonomy: `(-1,2,2,3)`
exercises the target-level "Other exceptional / uncertified" row (case (iv)) for its `61` missing
admissible curvatures, and `(-6,11,14,15)` exercises the "Reciprocity-obstructed" row (case (iii))
concretely for the `2n^2`, `3n^2`, `6n^2` families.

## 6. Nonclaims → Lean/lab cross-check

`THEOREMS.md` §G13 "6. Nonclaims" items 1 (no novelty for Bourgain-Fuchs/Bourgain-Kontorovich/
Haag-Kertzer-Rickards-Stange) and 5 (congruence admissibility is local and incomplete; reciprocity is a
separate residual type) are directly cross-checked by **one** lab:

- **G13-L1** (`lab/foundations_vi_lab/g13_saturation/apollonian.py`): an exact-integer Descartes-reflection
  BFS census of two Apollonian root quadruples, bounded at curvature `300000` (reduced from the design
  spec's aspirational `10^6` after disclosed feasibility probing — `100000` took approximately `10s`,
  `300000` took approximately `42s`). Before any lab code was written, the manager dispatched a dedicated
  literature-verification pass (matching the G11 Wang-tile precedent) that read the actual paper
  (Haag, Kertzer, Rickards, Stange, "The local-global conjecture for Apollonian circle packings is false,"
  *Annals of Mathematics* 200(2), 749-770, 2024, arXiv:2307.02749) and caught a citation-fidelity risk in
  `design/04_LABS.md`'s spec: `(-1,2,2,3)` (the "bug-eye" packing) is explicitly named in the paper's own
  Corollary 2.6 as one of the exceptions where the local-global conjecture **may still hold** — it is
  *not* one of the proven-obstructed examples. The lab was redesigned around this correction to use
  `(-1,2,2,3)` only as the clean baseline (`THEOREMS.md`'s own cited packing, no reciprocity claim), and
  to introduce `(-6,11,14,15)` (the same admissible residue type, per the paper's Theorem 2.4, type
  `(8,11,-1)`) as the genuine reciprocity-obstruction exhibit: Theorem 2.4 proves the quadratic families
  `2n^2`, `3n^2`, `6n^2` never appear in that packing's orbit at all, with the corresponding false residue
  classes `2, 3, 6, 18 (mod 24)` all admissible per the congruence audit. (External review, 2026-07-07,
  correctly caught a wording imprecision here: not every individual value of `2n^2`/`3n^2`/`6n^2` is
  itself admissible mod 24 — independently confirmed by the manager, exactly half of each family's values
  land in an admissible residue class. The theorem excludes the whole family regardless of individual
  admissibility, which is exactly why G13-L1's all-values zero-hit check is a valid, if stronger-than-
  strictly-necessary, consistency check.)

  The manager independently hand-derived the Descartes reflection formula from scratch via Vieta's
  formulas on the Descartes quadratic (confirming `k_i' = 2*(sum of other three) - k_i`), hand-traced the
  first two reflections from `(-1,2,2,3)` and confirmed they match the code's actual output exactly, and
  independently reran both quadruples' orbit generation at a bound (`150000`) different from Coder's
  tested `10000`/`100000`/`300000`. This independent rerun reproduced both key results: the baseline's
  `61` missing admissible curvatures (matching the arXiv version's Table B figure of `61` missing up to
  `N=10^10` — that table is explicitly marked "not in published version," a correction external review
  caught after this note originally cited it as "the paper's own published Table A" — a striking
  independent cross-validation of implementation correctness regardless) and zero hits across
  all three reciprocity families for `(-6,11,14,15)`. The verdict correctly scopes this as a finite
  consistency check for `reciprocity_compatibility_observation`, explicitly disclaiming any discharge of
  `relative_density_theorem`'s imported hypotheses and any reproof, extension, or contradiction of the
  cited papers. Reviewer's first pass flagged one FIX-FIRST finding (the design-spec `10^6 -> 300000`
  scale reduction was not disclosed in the generated verdict); this was corrected in the verdict
  generator and the artifact was regenerated, not hand-edited.
