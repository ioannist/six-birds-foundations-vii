## 2. Theorem → Lean target

The two-part conclusion (existence + universal aperiodicity) is `g11_global_anti_symmetry`
(`admissible_configurations_exist` + `hierarchy_forces_aperiodic` combined). Both component theorems are
**fully constructive — zero axioms at all**, not even `propext`/`Quot.sound` (tied with G2 for the
cleanest axiom profile of any law mechanized in this project so far).

**The one real design decision**: `[H-G11-hierarchy]` needed a choice between a direct
hierarchy-implies-non-periodicity shortcut and a more faithful encoding preserving the prose's "some scale
`k`" structure. The Lean file uses the latter: an abstract `Scale` type, `BreaksAt` (forced structure at
scale `k` isn't `p`-invariant), and a separate `ForcedBreaksPeriod` hypothesis (breaking at some scale
genuinely blocks period-invariance — this is the real mathematical content standing in for "the hierarchy
is locally forced by the rules of `C`"). `Hierarchy` itself is stated as a disjunction
(`p = P0 ∨ ∃ k, BreaksAt x k p`) rather than the prose's literal conditional — constructively cleaner for
an arbitrary period type, and confirmed (both by the manager and Reviewer) not to weaken the claim.

## 3. Proof spine → Lean target

`hierarchy_forces_aperiodic`'s proof is a genuine (if modest) "packaging" step: case-split on
`Hierarchy`'s disjunction; if `p = P0`, done; if `∃ k, BreaksAt x k p`, derive `False` from
`ForcedBreaksPeriod` applied to the actual period-holding hypothesis, closing by `False.elim`. Hand-traced
by the manager to confirm this isn't a hypothesis restatement but a real logical step.

## 6. Nonclaims → Lean/lab cross-check

`THEOREMS.md` §G11 "6. Nonclaims" item 5 (G11-L1 is a finite-period exhibit, not a domino-problem decision
procedure) is directly cross-checked by the lab: `lab/foundations_vi_lab/g11_symmetry/{wang_sat,run}.py`
implements a Wang-tile torus SAT encoder, run against the **real, literature-cross-checked** Jeandel-Rao
11-tile aperiodic set (citation resolved via a dedicated research pass **before** any code was written —
cross-checked Jeandel & Rao's own paper, arXiv:1506.06492, against an independent reproduction, Labbé's
arXiv:1808.07768 and published code — all 11 tiles matched exactly). The manager independently verified
the SAT encoding three ways beyond trusting the solver: hand-traced the encoding logic, brute-forced the
`1×1` case by hand (all 11 tiles fail to self-match, confirming UNSAT), and wrote an independent
from-scratch script exhaustively enumerating all `11^4=14641` possible `2×2` assignments (found zero valid
tilings, confirming UNSAT independently of the SAT solver). Two scope reductions are explicitly disclosed
in the verdict (Reviewer required this in a FIX-FIRST round): the lab tests rectangular `p1×p2` torus
period lattices only (not arbitrary non-axis-aligned periods), and records only full-instance UNSAT
results with committed DIMACS (no UNSAT-core/minimal-defect-region extraction).

`python-sat` is this project's **first external lab dependency** (a spec-granted exception to the
stdlib-only house rule) — now properly declared in `lab/pyproject.toml` after a Reviewer-caught gap.
