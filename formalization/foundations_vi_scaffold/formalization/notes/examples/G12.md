## 1. Setup → Lean target

`THEOREMS.md` §G12 "1. Setup" (a carrier `X` with graph relation `E`, a group `Gamma` acting transitively
by automorphisms of `E`, a proper `k`-coloring, and the finite certificate `cert_k(W)` for a finite
`W subset X`) is mechanized in `lean/SixBirdsFoundationsVI/Laws/G12FiniteWitnessRadiation.lean` at the
level actually needed for the theorem's logical content, not the full geometric/group-theoretic setup:
`ProperKColoring E k c` (a total coloring bounded `<k` everywhere, proper across every `E`-edge) and
`FiniteWitnessObstruction E k W` (no coloring properly `k`-colors the induced finite subgraph on list
`W` — the Lean rendering of "`cert_k(W)` proves `chi(G[W])>k`"). `Gamma`'s group structure, transitivity,
Euclidean geometry, unit-distance coordinates, and SAT/DIMACS certificate machinery are **not**
constructed generically — calibration/lab content (§6).

**No Lean imports.** Standalone, like every prior law's file — confirmed by direct grep.

## 2. Theorem → Lean target

Three declarations of markedly different character. `no_global_k_coloring` is the flagship, genuinely
unconditional restriction argument: a finite witness on `W` forbids any global `ProperKColoring` of `X`.
`orbit_radiation` is likewise genuinely unconditional: a `StructurePreserving` map (full iff, faithful to
"automorphisms of E") sends a finite witness to another finite witness — and, notably, **does not require
`gamma` to be injective or bijective**, even though the Setup's automorphism language would license the
stronger case; both Coder and the manager independently confirmed this with fresh test instances (§3).
`CompactnessBridge` + `finite_witness_iff_no_global_coloring` package the de Bruijn-Erdos compactness
principle as an explicit **named, unproved** hypothesis, combined with `no_global_k_coloring` into a full
biconditional using pure intuitionistic logic — no classical/choice machinery is smuggled into the
packaging itself. **All three named theorems are fully axiom-free** — not even `propext`, a cleaner
result than most prior laws in this catalog.

## 3. Proof spine → Lean target

`no_global_k_coloring`'s proof is a direct restriction: a hypothetical global coloring, restricted in
scope to `W`, would witness-defeat `FiniteWitnessObstruction` by construction. `orbit_radiation`'s proof
is a pullback: a hypothetical coloring of `W.map gamma`, composed with `gamma`, produces a coloring of `W`
using only the forward direction of `StructurePreserving` — no inversion of `gamma` is needed, which is
exactly why injectivity turns out to be unnecessary. The manager independently re-derived and verified
both arguments from scratch: (a) a "triangle" test (`Etri x y := x≠y`, `W=[0,1,2]`, `k=2`), hand-proved
not 2-colorable by pigeonhole via `omega`, then run through `no_global_k_coloring` and `orbit_radiation`
with `gamma:=(·+1)`, producing the expected shifted witness `[1,2,3]`; (b) a test **specifically targeting
the no-injectivity claim** (`Epar x y := x%2≠y%2`, `gamma:=(·%2)`, provably non-injective since
`gamma 0 = gamma 2 = 0` with `0≠2`), confirming `orbit_radiation` still produces a valid witness
(`Wpar.map gpar = [0,1,0]`, a list with a genuine duplicate from the collapse) — a nontrivial, from-scratch
confirmation, not merely a re-check of Coder's own claim.

## 6. Nonclaims → Lean/lab cross-check

`THEOREMS.md` §G12 "6. Nonclaims" items 1 (no exact chromatic-number determination) and 4 (no novelty for
de Grey/Heule/Parts/Polymath16/de Bruijn-Erdos) are directly cross-checked by **one** lab:

- **G12-L1** (`lab/foundations_vi_lab/g12_finite_witness/`): a real, literature-sourced 826-vertex
  unit-distance graph (the Heule/Polymath16 intermediate construction, vendored from
  `cs.utexas.edu/~marijn/CNP/826.{vtx,edge}`), verified end-to-end as a genuine instance of `cert_4(W)`.
  Before any lab code was written, a dedicated literature-verification research pass (matching the
  G11/G13 precedent) confirmed the current smallest known published 5-chromatic unit-distance graph is
  509 vertices (Parts, arXiv:2010.12665) — raw coordinate data for that specific graph was not found
  publicly archived (checked arXiv ancillary files: 404; checked the Polymath16 wiki's linked Dropbox).
  **`826` is a valid vendored intermediate graph used by this lab, not the smallest available
  Heule/Polymath public-data option**: an original version of this note (and of the research pass behind
  it) incorrectly claimed the `553`/`529`-vertex Heule intermediates also had no public coordinate data,
  and that `826` was therefore "the smallest well-documented graph" available. External review (2026-07-07)
  caught this — the original pass missed Heule's own `github.com/marijnheule/CNP-SAT` repository, which
  publicly hosts matched `.vtx`/`.edge` data for `510`/`517`/`529`/`553`/`610`/`633`/`803`, all smaller
  than `826`, independently confirmed by the manager via the GitHub API. This scoping decision and its
  correction are disclosed plainly in `data/PROVENANCE.md`, the prediction, and the verdict, not silently
  passed off as using "the" record-holder or "the" smallest available public instance.

  Exact-arithmetic unit-distance verification covered all `4273` declared edges via two independent
  methods (pure symbolic simplification — explicitly avoiding `sympy.nsimplify`, which the manager found
  introduces spurious numerical-guessing false positives when misapplied — and a 60-digit-precision
  numeric cross-check), both with zero failures; `2000` random sampled non-edges confirmed not
  accidentally at unit distance. Non-4-colorability was verified via a real SAT solve on the standard
  4-coloring CNF encoding (`3304` variables, `22874` clauses). The manager independently reconstructed
  this exact CNF from scratch (before writing the Coder packet) and, after Coder's implementation,
  directly diffed the committed file against the independent reconstruction as clause SETS: **byte-for-
  byte identical, zero symmetric difference**. Three independent solver invocations then agreed on UNSAT:
  the manager's own `Glucose3` run (`629.10s`) and `Kissat404` run (`308.38s`), plus Coder's own
  `kissat404` run (`533.18s`) on the identical clause set. The verdict discloses plainly that this UNSAT
  determination is solver-verified, not independently proof-checked — the `826`-vertex instance used has
  no DRAT/resolution certificate in Heule's `CNP-SAT` repository.

  **Correction (2026-07-07, external review):** the original literature-verification pass concluded, and
  this note originally repeated, that no smaller Heule/Polymath graph had public coordinate-plus-edge
  data, and that no graph in this literature stream had a public DRAT certificate at all. Both claims were
  wrong. External review found Heule's own `github.com/marijnheule/CNP-SAT` repository (missed by the
  original pass, which checked only his personal page and two other repos) publicly hosting `.vtx`/`.edge`
  data for `510`/`517`/`529`/`553`/`610`/`633`/`803` — several smaller than the `826` used here — plus
  public DRAT certificates for the `517`/`529`/`553`/`610`/`633`/`803` 4-coloring UNSAT instances,
  independently confirmed by the manager via the GitHub API. `826` itself still has no DRAT certificate in
  that repository, so this lab's own solver-verified (not proof-checked) scoping for the `826` instance
  remains accurate; only the broader "no such data/certificate exists anywhere" framing was wrong. See
  `data/PROVENANCE.md` for the full correction.
