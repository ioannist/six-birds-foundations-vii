## 2. Theorem → Lean target

`boundary_persistence`: given `Lossful D`, `Protect D b rho I`, `Regen D I`, and `I x0`, proves for every
`n`: `I (Iterate D n x0)` and `b (Iterate D n x0) = Iterate rho n (b x0)`. Matches the prose's two-part
conclusion exactly. Ordinary `Nat` induction — no well-foundedness needed (unlike G2/G8; see §5's gate
discussion for what this means for the promotion panel).
