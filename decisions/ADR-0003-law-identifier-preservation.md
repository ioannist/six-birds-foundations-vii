# ADR-0003 — Preserve original law identifiers

**Status:** accepted.

The F/E/G/no-go registries retain the source identifiers exactly. Foundations IV contains 52 rows from F2 through F53 with split labels F13a/F13b and F15a/F15b and identifier gaps. The repository does not normalize these into F1–F52 because that would break provenance and cross-paper citations.
